4. 주의사항

1. SDK CDN 로딩: index.html에서 Auth Client SDK를 CDN으로 로드. 현재 CDN 버전 이슈로 Date.now() 캐시 무효화 적용 중. CDN 최신 버전 확인 필요.
2. apiUrl 필수: authClient.ts에서 apiUrl: VITE_API_URL 설정 필수. 빠지면 SDK가 토큰 교환을 FE origin(5173)으로 보내 실패.
3. main.tsx 부트스트랩: SDK initAuth()가 React 렌더보다 먼저 실행되는 async 패턴. createBrowserRouter 전환 시 replaceState 이후 라우터 생성 필요.
4. ProtectedLayout useProfileCheck: 매 보호 라우트 접근 시 /api/v1/user/status 호출. 성능 캐싱 고려 필요.
5. LoginForm 미사용: LoginForm.tsx 파일은 아직 존재하지만 어디서도 import하지 않음. 정리 시 삭제 가능.

5. SSO 인증 플로우 요약

일반 회원 로그인: LoginPage [로그인] 클릭 → auth.login() → Auth 서버 로그인 페이지로 리다이렉트 → Auth 서버에서 로그인/회원가입 → localhost:5173/auth/callback?code=xxx 으로 복귀 → main.tsx: handleRedirectResult() → 토큰 교환 (학심정 BE 프록시) → GET /api/v1/user/status 확인 → 미등록: /auth/complete-profile (성별/역할 입력) → user 생성 → 등록: roleCode 기반 리다이렉트 (/dashboard 또는 /student/exams) 게스트 참여: 초대 링크 접속 → [게스트로 참여하기] → 이메일 입력 → 이메일 인증 (학심정 자체) → POST /group/join-guest → Auth 게스트 토큰 발급 → auth.setGuestToken(accessToken) → /guest/exams 이동
