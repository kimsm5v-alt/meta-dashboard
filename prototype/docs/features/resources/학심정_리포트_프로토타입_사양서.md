# 학심정 수업 리포트 — 프로토타입 사양서

## 개요

학심정 수업의 리포트 화면 프로토타입. React로 제작.
매쓰캔버스 리포트를 참고한 학생별/페이지별 보기 구조.

---

## 데이터 모델

### 수업 데이터 (수업 참여 학생 × 세트지)

```typescript
interface ClassReportSummary {
  activityMode: "수업" | "과제";           // 실시간 / 비실시간
  participantCount: number;               // 하나라도 제출한 학생 수
  assignedCount: number;                  // 배정된 전체 학생 수
  submitRate: number;                     // 참여/배정 × 100
  avgCorrectRate: number;                 // 정답 있는 문항만, 전체 학생 평균
  unsubmittedCount: number;              // 미제출 학생 수
  avgDuration?: number;                   // 평균 활동 시간 (초) — 미확인 필드
}
```

### 세트지 데이터 (학생 × 세트지)

```typescript
interface StudentActivity {
  studentId: string;
  studentName: string;
  statusCd: 2 | 3 | 4 | 5;              // 2=대기, 3=제출, 4=진행중, 5=완료
  period: { start: string; end: string }; // 과제 기간
  score?: number;                         // 100점 환산 — 미확인
  submittedAt?: string;                   // 제출 시각 — 미확인
  duration?: number;                      // 소요 시간 (초) — 미확인
}
```

### 응답 데이터 (학생 × 아티클)

```typescript
interface ResponseData {
  articleId: string;
  studentId: string;
  submitAnswer: string;                   // 유형별로 값이 다름
  errata: 1 | 2 | 3 | 4;                // 1=정답, 2=오답, 3=부분, 4=채점불가
  itemType: string;                       // choice, ox, short, drawing, audio 등
  gradingType: 1 | 2 | 3;               // 1=자동, 2=참여, 3=측정
  captureImage?: string;                  // 뷰어 캡처 이미지 URL
}
```

### 아티클 (페이지) 정보

```typescript
interface Article {
  id: string;
  order: number;                          // 페이지 번호
  nature: "개념" | "활동" | "문항";        // 콘텐츠 성격
  itemType: string;                       // choice, drawing, audio 등
  title: string;                          // 아티클 제목
  correctAnswer?: string;                 // 정답 (문항만)
  selFactor?: string;                     // SEL 역량요인
}
```

## 화면 사양

### 화면 1: 수업 결과보기 — 상단 대시보드

전체 활동 목록의 집계. 이 프로토타입에서는 단일 활동 기준.

**레이아웃:**
- 상단: 카드 4개 가로 배열
- 하단: 리포트 카드 리스트 (상태 필터 칩 포함)

**카드 4개:**
| 카드 | 값 | 계산 |
|---|---|---|
| 현재 진행 중 활동 | 건수 | 활동 상태 count |
| 이번 주 진행 활동 | 건수 | 기간 필터 |
| 평균 참여율 | % | submitRate |
| 미제출 학생 | 명 | unsubmittedCount |

**리포트 카드:**
- 상태 배지 (진행중/완료)
- 제목, 수업/과제 배지, 배포 반, 기간
- 참여 n/m명
- "리포트" 버튼 → 화면 2로 이동

---

### 화면 2: 리포트 상세 — 상단 대시보드

세트지 1건 선택 후 진입. 요약 + 탭 전환.

**레이아웃:**
- 상단: 활동 정보 (제목, 수업/과제 배지, 기간, 반)
- 중단: 요약 카드 4개
- 하단: 탭 (페이지별 보기 / 학생별 보기)

**요약 카드 4개:**
| 카드 | 값 | 계산 |
|---|---|---|
| 참여 인원 | n/m명 (%) | participantCount / assignedCount |
| 평균 정답률 | % | avgCorrectRate (문항만) |
| 제출률 | % | submitRate |
| 평균 활동 시간 | 분 초 | avgDuration → 분:초 변환 |

**SEL 역량 배지:** 세트지에 포함된 SEL 요인 목록 표시

---

### 화면 3: 리포트 상세 — 페이지별 보기

매쓰캔버스 "페이지별 보기" 참고. 아티클 1개 선택 → 전체 학생 응답.

**레이아웃:**
- 좌측: 페이지 목록 (번호 + 성격 배지: 개념/활동/문항)
- 우측 상단: 선택한 페이지 정보 (제목, 성격, SEL 요인)
- 우측 본문: 성격별 분기

**목록 보기 (성격별 분기):**

| 성격 | 표시 방식 |
|---|---|
| 개념 | 학생별 조회 여부 리스트 (●봄 / ○안봄) |
| 활동 — 텍스트 (essay/short/choice) | 학생별 응답 텍스트 리스트 |
| 활동 — 그리기 (drawing) | 학생별 캡처 썸네일 그리드 (매캔처럼). 각 카드에 학생 이름 + 소요 시간 + 날짜 + "활동 보기" 버튼 |
| 활동 — 녹음 (audio) | 학생별 제출 여부 + 재생 버튼 + 녹음 길이 |
| 활동 — 녹화 (video) | 학생별 제출 여부 + 재생 버튼 + 녹화 길이 |
| 활동 — 의견보드 (board) | 학생별 의견 텍스트 리스트 |
| 문항 — 선택형 (choice) | 선택지별 분포 바 차트 + 정답 표시. 하단에 학생별 O/X |
| 문항 — OX/TF | 학생별 O/X 리스트 |
| 문항 — 단답/초성 | 학생별 답 vs 정답 비교 리스트 |
| 문항 — 서술/자유단답 | 학생별 텍스트 답안 + 교사 채점 영역 (O/△/X) |

**상세 보기 (캡처 클릭 시):**
- 캡처 이미지 확대
- 활동이면: 활동 재생 버튼 (그리기) 또는 재생 버튼 (녹음/녹화)
- 문항이면: 학생 답 vs 정답 비교

---

### 화면 4: 리포트 상세 — 학생별 보기

매쓰캔버스 "학생별 보기" 참고. 학생 1명 선택 → 전체 페이지 응답.

**레이아웃:**
- 좌측: 학생 리스트 (이름 + 제출 상태 배지)
- 우측 상단: 학습 요약 카드

**학습 요약 카드 3개:**
| 카드 | 값 | 계산 |
|---|---|---|
| 활동 페이지 | n/m p | 제출한 아티클 수 / 전체 아티클 수 |
| 정답률 / 맞춘 문제 | % · n/m개 | errata=1 수 / 문항 수 (문항만) |
| 활동 시간 / 제출 시간 | 분 초 · 날짜 | duration → 분:초 + submittedAt |

**상세 활동 내역:**
- 페이지별 리스트 (페이지 번호 + 성격 배지)
- 각 페이지: 캡처 썸네일 + 정오 뱃지 (문항만) + 소요 시간
- "활동 보기" 버튼 (그리기/녹음/녹화인 경우)
- "전체 보기" 버튼 (모든 페이지 한번에)

**캡처 클릭 시 상세:**
- 화면 3의 상세 보기와 동일

---

### 화면 5: 학생 리포트 (학생 본인)

학생이 자기 결과를 보는 화면.

**5-1. 간단 대시보드:**
- 나한테 배정된 활동 리스트
- 각 활동: 제목 + 제출 상태 배지 + 마감일
- 제출한 것: 정답률 표시

**5-2. 상세 리포트:**
- 요약: 활동 페이지 수 + 정답률 + 활동 시간
- 페이지별 내 캡처 + 정오 뱃지
- 캡처 클릭: 내 답 vs 정답 비교 + 해설 (있는 경우)
- 내 그리기/녹음 다시보기

```

    └── StudentDetailReport (5-2)
```

## 미확인 사항 (프로토타입에서는 목 데이터로 대체)

| 항목 | 프로토타입 처리 |
|---|---|
| 소요 시간 (duration) | 목 데이터로 표시 (320초 → "5분 20초") |
| 제출 시각 (submittedAt) | 목 데이터로 표시 |
| 점수 (score) | errata 합산으로 계산해서 표시 |
| 뷰어 캡처 이미지 | placeholder 이미지 사용 |
| 그리기 재생 | "활동 보기" 버튼만 표시 (실제 재생 없음) |
| 녹음/녹화 재생 | "재생" 버튼만 표시 (실제 재생 없음) |
