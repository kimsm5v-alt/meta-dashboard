# 수업 자료실(resources) — 플로우 검수 시나리오

> 대상: `feat/v2-prototype-lesson` / `prototype/src/features/resources/` (Phase 0~8 전체)
> 진입: `/lesson` → `ResourceListPage`
> 목적: 화면 플로우 + **집계 정합성** + 3대 분기(스코프·역할·리포트 상태) 조합을 빠짐없이 검수.
> 데이터: 전부 결정적 mock. 같은 입력 → 항상 같은 수치. 새로고침해도 값이 흔들리면 그게 버그.

## 검수 방법
- [ ] `npm run dev`(또는 vite 직접) → `/lesson` 200 확인, 콘솔 에러 0
- [ ] 각 시나리오: **Given(전제) → When(조작) → Then(기대결과)** 순으로 확인 후 체크
- [ ] ✅ 통과 / ⚠️ 이상 있음(비고에 현상·재현경로 기록) 로 표시

## 검수 기준 데이터 (mock 고정값)
| 반 | 리포트(상태·인원) | 문항형 포함(정답률 타일) |
|---|---|---|
| 2-3반 | r1 감정체크인(진행중·25), r3 관계역할극(진행예정·25), r4 갈등해결(완료·25) | r4 ✅ / r1 ❌ |
| 2-4반 | r2 자기인식(진행중·24), r6 정서안정호흡(완료·24) | r2 ✅ / r6 ❌ |
| 2-5반 | r5 강점찾기(완료·24), r7 자기관리목표(진행예정·24) | r5 ❌ / r7(진행예정) |

- **나의 자료(세트지)**: m1·m2 배포됨, m4·m5 완료(→ 편집잠금 🔒), m3·m6 임시저장(→ 편집가능)
- **진행예정(r3·r7)**: participation = 0 → 모든 집계 빈상태
- **완료 ≈ 82%+ 참여 / 진행중 ≈ 55%+ 참여** (해시 기반, 반별 상이)

# Phase 0 · 기반 · 셸 · 스코프

### 0-1. 진입 & 초기 상태
- [ ] Given `/lesson` 진입 · When 첫 렌더 · Then 기본 탭 = **공유 자료실**, 역할 = **교사**, 브레드크럼 `수업 › 공유 자료실`
- [ ] 콘솔에 `useResources must be used within` 등 Context 에러 없음

### 0-2. 스코프 파생 (LNB 연동)
- [ ] Given LNB 반 미선택(전체) · Then 스코프 = **전체**, 브레드크럼에 반명 미표기
- [ ] Given LNB에서 **2-3반** 선택 · Then 브레드크럼 `수업 › {탭} › 2-3반`, 자료실이 **반 큐레이팅** 뷰로 전환
- [ ] **스코프 이탈 규칙**: 리포트 상세를 연 상태에서 스코프를 바꾸면 → 상세에서 자동 이탈(목록 복귀). *(RESET_REPORT)*

### 0-3. 토스트
- [ ] 토스트 유발 액션(예: 카드 "저장") 시 하단 중앙에 뜨고 **~1.9초 후 자동 소멸**, 연속 호출 시 타이머 리셋(겹침 없음)

# Phase 5 · 리포트 상세 ★정합성 핵심

> **최우선 검수 포인트**: 목록 카드의 참여수 == 상세 요약의 참여수 == 슬라이드/학생 집계. 전부 `participation(r)` 단일 소스. 한 곳이라도 어긋나면 버그.

### 5-1. 진입/이탈
- [ ] 목록에서 r1 카드 클릭 → 상세 진입(기본 탭=슬라이드별, 첫 슬라이드 선택)
- [ ] "돌아가기" → 목록 복귀, 필터/스코프 유지
- [ ] 스코프 변경 시 상세 자동 이탈(0-2 재확인)

### 5-2. 요약 정합성 (r4 완료·2-3반)
- [ ] 목록 r4 카드 참여수 **기록** → 상세 진입 후 요약 참여수 **동일**해야 함
- [ ] 응답 완성도(%), 평균 활동시간 표기, 값이 새로고침해도 불변

### 5-3. 조건부 정답률 타일
- [ ] **문항형 포함(r2·r4)**: 정답률 타일 노출
- [ ] **활동형만(r1·r5·r6)**: 정답률 타일 **숨김**(0%가 아니라 미표시)

### 5-4. 슬라이드별 탭 — 문항형
- [ ] r4 슬라이드1(갈등상황, 정답=상대 말 먼저 듣기): 선택지 분포 막대 + 슬라이드 정답률 표기
- [ ] 분포 합계 == 해당 슬라이드 응답 인원, 정답 인덱스 강조

### 5-5. 슬라이드별 탭 — 활동형
- [ ] r1 슬라이드: 응답 표본(이름:응답값) 목록, 기본 접힘 → "펼치기"로 확장
- [ ] "외 N명" 표기가 실제 응답 인원과 일치, 펼침 토글 key-reset 정상

### 5-6. 학생별 탭
- [ ] r4 학생 목록(2-3반 8명 표본): 제출/미제출 상태 배지(미제출/정답/오답/제출) 색 구분
- [ ] 학생 클릭 → 개인 타임라인, 개인 정답률(문항형) 표기
- [ ] 개인 집계 합 ≈ 전체 요약과 논리적으로 정합(개인 정답 합 ≤ 전체)

### 5-7. 진행예정 빈 상태 (r3·r7)
- [ ] r3 상세 진입 · Then 슬라이드별·학생별 **양 탭 모두 빈 상태**(participation=0), 지표 0/빈 처리
