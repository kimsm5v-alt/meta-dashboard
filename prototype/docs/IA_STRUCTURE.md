# IA (Information Architecture) — Depth 구조

> 서비스 특장점인 **코칭**을 1Depth GNB로 꺼내서 부각시킨 구조
> LNB는 4안과 동일하게 반 목록 ↔ 학생 목록 전환

---

## 전체 레이아웃

```
┌──────────────────────────────────────────────────────┐
│  📚 학습심리정서검사  │  검사  코칭  수업  AI어시스턴트  │  ← GNB
│  ↑ 클릭 시 홈        │                                │
├──────────┬───────────────────────────────────────────┤
│ 보기 기준  │                                           │
│          │  [서브탭 pill]  ← 반 선택 시에만 노출         │
│ ⚙ 그룹관리│                                           │
│ ─────── │  콘텐츠 영역                                │
│ 내 반     │                                           │
│ ● 1-1반  │                                           │
│ ● 1-2반  │                                           │
│ ● 1-3반  │                                           │
│          │                                           │
│  ← LNB   │                                           │
└──────────┴───────────────────────────────────────────┘
```

## GNB (상단 탭)

| 메뉴 | 서브탭 (반 선택 시) | 핵심 역할 |
|------|---------------------|-----------|
| 홈 | — | 로고 "학습심리정서검사" 클릭 시 진입 |
| 검사 | 검사관리 · 결과보기 · 학생 상담 · 변화추적 | 데이터 확인 영역 (검사→결과→상담→변화) |
| 코칭 | 학급 코칭 · 개별 코칭 | 교사 실행 영역 (서비스 특장점) |
| 수업 | TBD | 수업 관리 |
| AI어시스턴트 | TBD | AI 도우미 |

- **로고 "학습심리정서검사" 클릭** = 홈 화면 (GNB 탭 전부 비활성)
- **GNB 탭 클릭** = LNB 반 목록으로 복귀, 전체 현황

## LNB (좌측 사이드바) — 4안과 동일

### 상태 1: 반 목록 (기본)

```
보기 기준
──────────
⚙ 그룹관리
──────────
내 반
● 1-1반      응시율 85% · 상담 3
● 1-2반      검사 배포 가능
● 1-3반      검사 배포 가능
```

### 상태 2: 학생 목록 (반 선택 후)

```
보기 기준
──────────
← 반 목록
──────────
1-2반
● 반 전체    ●        ← 기본 선택
──────────
학생
  김채미
  문순민      ●
  임지영
  이리사
  김다영
```

### LNB 상태 전환 트리거

| 트리거 | 결과 |
|--------|------|
| 반 클릭 | 반 목록 → 학생 목록, 서브탭 노출, "반 전체" 기본 선택 |
| ← 반 목록 | 학생 목록 → 반 목록, 서브탭 숨김, 전체 현황 |
| GNB 탭 클릭 | → 반 목록, 서브탭 숨김, 전체 현황 |
| 로고 클릭 | → 반 목록, GNB 비활성, 홈 화면 |
| 학생 클릭 | 학생 목록 유지, 해당 학생 하이라이트 |
| 반 전체 클릭 | 학생 목록 유지, 학생 선택 해제 |
| 서브탭 전환 | 학생 목록 유지, 학생 선택 초기화 → "반 전체" |

## [GNB] 검사

### 반 미선택: 전체 현황 (서브탭 없음)

- 요약 카드 (관리 중인 반, 진행 중 검사, 결과 확인 가능, 미응시 학생)
- 검사 현황 테이블 (반 / 검사지 / 회차 / 응시율 / 액션)

### 반 선택: 서브탭 노출

| 서브탭 | ◀ | 반 전체 | 학생 선택 |
|--------|---|---------|----------|
| 검사관리 | ✗ | 학생 목록, 검사 상태 (시작/진행중/종료), 회차 관리 | — |
| 결과보기 | ◀ | 반 종합 결과, 요인별 분포, 위험군, 유형별(LPA), 강점/보완점 | 요인별 점수, 유형 설명, AI 총평, 강점/보완점 |
| 학생 상담 | ◀ | 우선순위 추천, 반 상담 기록 (학생별/날짜별 필터) | 결과 요약 카드, 질문 추천, 상담 메모, → [코칭] 연결 |
| 변화추적 | ◀ | 사전/사후 비교, 개입 이력 타임라인, 출력/공유 | 1차→2차 변화 결과, 개입 이력 |

> **플로우**: 검사관리 → 결과보기 → 학생 상담 → 변화추적 (데이터 확인 흐름)

## [GNB] 코칭

### 반 미선택: 전체 현황 (서브탭 없음)

- 요약 카드 (코칭 진행중)
- 전체 코칭 현황

### 반 선택: 서브탭 노출

| 서브탭 | ◀ | 반 전체 | 학생 선택 |
|--------|---|---------|----------|
| 학급 코칭 | ✗ | 반 특성 분석, SEL 콘텐츠 추천, 반 운영 전략 | — |
| 개별 코칭 | ◀ | 학생 목록, 코칭 현황 | 결과 요약 카드, 코칭 전략, 교사/학생/학부모 가이드 |

> **포인트**: 검사 메뉴와 분리 → 코칭만 독립적으로 확인 가능

## 선택 이유

### ✅ 장점
- 코칭이 1Depth에 있어 **서비스 특장점 부각**
- 검사 내에서 시행→결과→상담→변화추적이 자연스러운 **데이터 흐름**
- 코칭은 **교사 실행 영역**으로 깔끔하게 분리
- 변화추적이 검사 데이터 기반이라 검사 탭에서 찾는 게 직관적

### ⚠️ 고려사항
- 검사에서 상담 후 코칭으로 가려면 GNB 전환 필요
- 학생 상담 → 코칭 연결 링크로 보완

## 사용자 시나리오

```
1. 첫 진입 → 홈 화면 (로고 활성), LNB 반 목록
2. GNB [검사] 클릭 → 검사 전체 현황, 서브탭 없음
3. LNB [1-2반] 클릭 → LNB 학생 목록 전환, 서브탭 노출 (검사관리)
4. pill [결과보기] → 1-2반 종합 결과 (반 전체)
5. LNB [문순민] 클릭 → 문순민 결과 상세
6. pill [학생 상담] → 학생 초기화 → 1-2반 상담 우선순위
7. LNB [문순민] 클릭 → 문순민 상담 (질문 추천, 메모)
8. pill [변화추적] → 학생 초기화 → 1-2반 사전/사후 비교
9. LNB [문순민] 클릭 → 문순민 1차→2차 변화 결과
10. "→ 코칭 연결" 클릭 or GNB [코칭] 클릭
11. LNB [1-2반] 클릭 → pill [개별 코칭] → LNB [문순민] → 코칭 전략
12. [← 반 목록] → 반 목록 복귀, 전체 현황
13. 로고 클릭 → 홈
```
