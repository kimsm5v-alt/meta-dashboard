## 🔗 주요 API 엔드포인트 요약

| 구분 | Method | Endpoint | 설명 |
|------|--------|----------|------|
| **인증** | POST | `/member/signup` | 회원가입 |
| | POST | `/member/login` | 로그인 |
| **그룹** | POST | `/group/create` | 그룹 생성 |
| | POST | `/group/join` | 그룹 참가 (회원) |
| | POST | `/group/join-guest` | 그룹 참가 (게스트) |
| **게스트** | GET | `/guest/exists` | 게스트 존재 확인 |
| | POST | `/guest/convert` | 게스트 → 회원 전환 |
| **검사** | POST | `/api/dgnss/tc/start` | 검사 시작 (교사) |
| | POST | `/api/dgnss/tc/end` | 검사 종료 (교사) |
| | GET | `/api/dgnss/st/new` | 문항 조회 (학생) |
| | POST | `/api/dgnss/st/saveOmr` | 답변 저장 (학생) |
| | POST | `/api/dgnss/st/submit` | 검사 제출 (학생) |
