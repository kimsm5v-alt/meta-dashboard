# 개인별 코칭 경로 랭킹 알고리즘

## 1. 개요

### 1.1 목적
같은 LPA 유형이라도 학생마다 38개 T점수 프로필이 다르므로, 유형별 코칭 경로를 개인의 취약 요인에 따라 관련도 순으로 정렬하여 맞춤형 코칭을 지원한다.

### 1.2 위치
- 지식그래프: `prototype/docs/meta-test/10_지식그래프.json`
- 알고리즘: `src/shared/utils/interventionRanker.ts`
- UI: `src/features/student-dashboard/components/CoachingStrategy.tsx`

## 2. 코칭 경로 데이터 구조

### 2.1 지식그래프 구조

지식그래프는 초등/중등별로 분리된 JSON 구조이다:

```json
{
  "elementary": {
    "directed": true,
    "multigraph": false,
    "nodes": [...],
    "links": [...]
  },
  "middle": {
    "directed": true,
    "multigraph": false,
    "nodes": [...],
    "links": [...]
  }
}
```

### 2.2 노드 유형 (Node Types)

| type | 설명 | 주요 속성 |
|------|------|----------|
| `Outcome` | 결과변수 (학업성취도) | id |
| `LPAClass` | LPA 유형 | name, class_num, color, school_level, description |
| `Factor` | 38개 요인 | name, factor_type, op_def, section_1, section_2, env_type, mean_elem/mean_middle, sd_elem/sd_middle, need_score_direction, badge_red_threshold, badge_orange_threshold, badge_gray_threshold |

### 2.3 링크 유형 (Link Types)

#### 2.3.1 MediationPath (매개경로)

X → M → Y 형태의 매개 경로이다.

```typescript
interface MediationPath {
  type: "MediationPath";
  lpa_class: string;           // 적용 유형 (예: "자원소진형")
  x: string | null;            // 독립변수 (null이면 direct)
  m: string;                   // 매개변수
  y: string;                   // 결과변수 (예: "학업성취도")
  path_type: "완전매개" | "mediation" | "direct";
  interpretation: string;      // 경로 해석
  strategy: string;            // 코칭 전략
  id: string;                  // 고유 ID (예: "MED_자원소진형_유능성_성장마인드셋")
}
```

#### 2.3.2 ModerationPath (조절경로)

X × Z → Y 형태의 조절 경로이다.

```typescript
interface ModerationPath {
  type: "ModerationPath";
  lpa_class: string;           // 적용 유형
  x: string;                   // 독립변수
  z: string;                   // 조절변수
  y: string;                   // 결과변수
  path_type: PathType;         // 조절효과 유형
  path_color: string;          // 시각화 색상
  keyword_interp: string;      // 해석 키워드
  keyword_strat: string;       // 전략 키워드
  interpretation: string;      // 경로 해석
  strategy: string;            // 코칭 전략
  z_factor_type: "positive" | "negative";
  z_need_direction: "lower_T_worse" | "higher_T_worse";
  id: string;                  // 고유 ID (예: "MOD_자원소진형_1_수업태도_게임 과몰입")
}
```

## 3. 랭킹 알고리즘

### 3.1 입력

| 파라미터 | 타입 | 설명 |
|----------|------|------|
| tScores | number[38] | 학생의 38개 T점수 |
| predictedType | StudentType | LPA 유형명 |
| schoolLevel | SchoolLevel | 'elementary' \| 'middle' |

### 3.2 처리 흐름

```
rankInterventions(tScores, predictedType, schoolLevel)
  │
  ├─ 1. 지식그래프에서 해당 학교급/유형의 경로 필터링
  │     ├─ MediationPath: lpa_class === predictedType
  │     └─ ModerationPath: lpa_class === predictedType
  │
  ├─ 2. 각 경로에 대해:
  │     ├─ x, m, z 필드에서 요인명 추출 → 38개 요인 인덱스 매칭
  │     ├─ needScore 계산 (절대적 필요도)
  │     └─ deviationScore 계산 (유형 내 상대적 취약도)
  │
  ├─ 3. 가중합 → relevanceScore
  │
  └─ 4. 점수 내림차순 정렬 → RankedPath[] 반환
```

### 3.3 요인명 → 인덱스 매핑

경로의 `x`, `m`, `z` 필드 값을 요인 인덱스에 매칭한다.

- 단일 요인: `'자기효능감'` → index 1
- 38개 요인에 없는 값: 무시 → 해당 요인은 기본 점수(0)

### 3.4 needScore (필요도 점수)

관련 요인의 T점수가 이상적 방향에서 얼마나 떨어져 있는지 측정한다. 요인의 `need_score_direction` 속성을 참조한다.

```
lower_T_worse (정적 요인):  gap = max(0, 50 - tScore)
higher_T_worse (부적 요인): gap = max(0, tScore - 50)

needScore = mean(gaps) × (100 / 30)   // 0~100 정규화
```

**예시**: 자기효능감(lower_T_worse) T=35 → gap = 50-35 = 15 → 높은 needScore

### 3.5 deviationScore (유형 편차 점수)

같은 유형의 평균(typeMeans) 대비 학생 개인이 얼마나 나쁜 방향으로 치우쳐 있는지 측정한다. 요인 노드의 `mean_elem` 또는 `mean_middle` 속성을 참조한다.

```
diff = tScore - typeMean

나쁜 방향 (lower_T_worse에서 평균보다 낮음 / higher_T_worse에서 평균보다 높음):
  가중 편차 = |diff| × 1.5

나은 방향:
  가중 편차 = |diff| × 0.5

deviationScore = mean(가중 편차) × (100 / 15)   // 0~100 정규화
```

### 3.6 최종 점수

```
relevanceScore = needScore × 0.6 + deviationScore × 0.4
```

| 가중치 | 의미 |
|--------|------|
| needScore 60% | 절대적 취약도 — T점수 자체가 낮은(또는 높은) 요인 우선 |
| deviationScore 40% | 상대적 취약도 — 같은 유형 내에서도 특히 약한 영역 반영 |

### 3.7 폴백 처리

| 상황 | 처리 |
|------|------|
| tScores가 없거나 길이 ≠ 38 | 경로 원래 순서 그대로, relevanceScore 100/90/80... |
| 요인 평균값 없음 | deviationScore = 0, needScore만으로 랭킹 |
| x, m, z에 38개 요인 외 값 | 해당 요인 무시, 매칭된 요인만으로 계산 |

## 4. 출력

### 4.1 RankedPath 인터페이스

```typescript
interface RankedPath {
  path: MediationPath | ModerationPath;  // 원본 경로 데이터
  relevanceScore: number;                // 0~100 (높을수록 관련도 높음)
  relevanceReason: string;               // 예: "자기효능감(T=35), 성장마인드셋(T=32) 보완 필요"
  involvedFactors: Array<{
    name: string;                        // 요인명
    score: number;                       // 학생 T점수
    typeMean: number | null;             // 유형 평균 (없으면 null)
  }>;
  scoreBreakdown?: {
    needScore: number;                   // 필요도 점수 (0~100)
    deviationScore: number;              // 유형 편차 점수 (0~100)
  };
}
```

### 4.2 UI 표시

코칭 전략 모달에서:

- 경로가 relevanceScore 내림차순으로 정렬
- **상위 5개만 기본 표시**
- **"더보기" 버튼**: 경로가 5개를 초과하면 하단에 `나머지 N개 경로 더보기` 버튼 표시
- 각 경로 카드에 **관련도 배지** 표시 (50+ 빨간, 25+ 주황, 그 외 회색)
- **path_type 배지** 표시 — 조절효과 유형별 색상 (path_color)
- 관련 요인의 **학생 T점수 + 유형 평균** 배지 표시
- 첫 번째 경로가 자동 선택됨

## 5. 예시

### 초등 자원소진형 학생 (T점수 예시)

| 요인 | 학생 T점수 | 유형 평균 | gap |
|------|:---:|:---:|:---:|
| 유능성 | 32 | 38.7 | 18 |
| 성장마인드셋 | 35 | 37.2 | 15 |
| 자기정서인식 | 45 | 41.7 | 5 |

**랭킹 결과** (needScore×0.6 + deviationScore×0.4):

1. **MediationPath**: 유능성 → 성장마인드셋 → 학업성취도 (완전매개): 관련도 **72**
2. **ModerationPath**: 자기정서인식 × 공부환경 → 학업성취도 (긍정 강화): 관련도 **45**
3. **ModerationPath**: 의미감 × 공부부담 → 학업성취도 (조합): 관련도 **38**

→ 같은 자원소진형이라도 정서인식이 특히 낮은 학생은 해당 조절경로가 상위로 올라옴

중등의 MediationPath는 `path_type`이 다양하다:

- `direct`: X 없이 M → Y 직접 경로 (x: null)
