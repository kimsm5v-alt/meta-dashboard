# Information Architecture (IA)

> META 학습심리정서검사 대시보드 정보 구조 (v2 - 고도화)

**Last Updated**: 2026-07-09

---

## 전체 레이아웃

```
┌──────────────────────────────────────────────────────────────────────┐
│  📚 학급 성장 관리  │  홈  검사  상담·코칭  수업  AI어시스턴트  │  AI도우미  │  ← GNB
├──────────┬───────────────────────────────────────────────────────────┤
│ 보기 기준  │  [서브탭 pill 버튼]                                        │  ← 반 선택 시에만 노출
│          ├───────────────────────────────────────────────────────────┤
│ ⚙ 그룹관리│                                                           │
│ ─────── │                                                           │
│ 내 반     │                   콘텐츠 영역                              │
│ ● 2-3반  │                                                           │
│ ● 2-4반  │                                                           │
│ ● 2-5반  │                                                           │
│          │                                                           │
│  ← LNB   │                                                           │
└──────────┴───────────────────────────────────────────────────────────┘
```

## GNB (상단 탭)

| 순서 | 메뉴 | 설명 |
|------|------|------|
| 1 | 홈 | 전체 현황 대시보드 |
| 2 | 검사 | 검사관리 · 결과보기 · 변화추적 |
| 3 | 상담·코칭 | 학생 상담 · 코칭 |
| 4 | 수업 | 수업 자료실 · 나의 수업 |
| 5 | AI어시스턴트 | 히스토리 · 자유질문 |

- 로고 클릭 = 홈 이동
- GNB 탭 클릭 시 → LNB 반 목록으로 복귀, 서브탭 숨김, 전체 현황 표시
- 오른쪽 끝: AI도우미 바로가기 버튼

## LNB (좌측 사이드바)

### 상태 1: 반 목록 (기본)

```
보기 기준
──────────
⚙ 그룹관리
──────────
내 반
● 2-3반      응시율 85% · 상담 3
● 2-4반      검사 배포 가능
● 2-5반      검사 배포 가능
```

### 상태 2: 학생 목록 (반 선택 후)

```
보기 기준
──────────
← 반 목록            ← 클릭 시 상태 1로 복귀
──────────
2-3반
● 반 전체    ●        ← 기본 선택
──────────
학생
  김채미
  문순민      ●        ← 선택된 학생
  임지영
  이리사
  김다영
```

### LNB 상태 전환 트리거

| 트리거 | 결과 |
|--------|------|
| 반 클릭 | 반 목록 → 학생 목록, 서브탭 노출, "반 전체" 기본 선택 |
| ← 반 목록 | 학생 목록 → 반 목록, 서브탭 숨김, 전체 현황 |
| GNB 탭 클릭 | → 반 목록, 서브탭 숨김, 전체 현황 |
| 로고 클릭 | → 반 목록, GNB 홈 활성, 홈 화면 |
| 학생 클릭 | 학생 목록 유지, 해당 학생 하이라이트 |
| 반 전체 클릭 | 학생 목록 유지, 학생 선택 해제 |
| 서브탭 전환 | 학생 목록 유지, 학생 선택 초기화 → "반 전체" |

## 콘텐츠 상세

### [홈] 전체 현황
- 검사 관련 요약
- 수업 관련 요약
- 캘린더 (상담/메모)

### [⚙ 그룹관리] (GNB 비활성)
- SSO 연동
- 반 생성/편집/삭제
- 학생 배정

---

## [GNB] 검사

### 반 미선택: 전체 현황
- 요약 카드 (관리 중인 반, 진행 중 검사, 결과 확인 가능, 미응시 학생)
- 검사 현황 테이블 (반 / 검사지 / 회차 / 응시율 / 액션)

### 반 선택: 서브탭 (pill 버튼)

| 서브탭 | ◀ | 반 전체 | 학생 선택 |
|--------|---|---------|----------|
| 검사관리 | ✗ | 응시율, 검사 시작/종료/취소/재진행, 회차 관리 | — |
| 결과보기 | ◀ | 종합 결과 요약, 요인별 분포, 위험군, 유형별(LPA), 강점/보완점 | 요인별 점수, 유형 설명, AI 총평, 강점/보완점, → [상담][코칭] 연결 |
| 변화추적 | ◀ | 사전/사후 비교, 개입 이력 타임라인, 출력/공유 | 1차→2차 변화 결과, 개입 이력 |

---

## [GNB] 상담·코칭

### 반 미선택: 전체 현황
- 요약 카드 (상담 대상, 코칭 진행중)
- 전체 상담·코칭 현황

### 반 선택: 서브탭 (pill 버튼)

| 서브탭 | ◀ | 반 전체 | 학생 선택 |
|--------|---|---------|----------|
| 학생 상담 | ◀ | 우선순위 추천 (상담우선, 감정활용, 신뢰도 주의), 반 상담 기록 (학생별/날짜별 필터) | 결과 요약 카드, 질문 추천, 상담 메모, 상담 기록 |
| 코칭 | ◀ | 반 특성 분석, SEL 콘텐츠 추천, 반 운영 전략 | 결과 요약 카드, 코칭 전략, 교사/학생/학부모 가이드 |

## [GNB] 수업

### 반 미선택: 전체 현황
- 수업 가이드 배너
- 전체 자료실
- 나의 수업 (수업 결과 리스트)

### 반 선택: 서브탭 (pill 버튼)

| 서브탭 | ◀ | 반 전체 | 학생 선택 |
|--------|---|---------|----------|
| 수업 자료실 | ✗ | 반 맞춤형 큐레이팅 (장점 추천 top3, 성장 로드맵), 전체 자료실 | — |
| 나의 수업 | ◀ | 반별 활동 리포트 (세트지별 → 학생별 → 슬라이드별) | 학생별 활동 결과, 슬라이드별 상세 |

## 사용자 시나리오 예시

```
1. 첫 진입
   → 홈 화면, LNB 반 목록

2. GNB [검사] 클릭
   → 검사 전체 현황 (요약 카드 + 테이블), 서브탭 없음

3. LNB [2-3반] 클릭
   → LNB 학생 목록으로 전환
   → 서브탭 pill 노출 (검사관리 | 결과보기 | 변화추적)
   → "반 전체" 기본 선택

4. pill [결과보기] 클릭
   → 2-3반 종합 결과 (반 전체)

5. LNB [문순민] 클릭
   → 문순민 결과 상세 (요인별 점수, AI 총평 등)

6. pill [변화추적] 클릭
   → 학생 선택 초기화 → 2-3반 변화추적 (반 전체)

7. [← 반 목록] 클릭
   → LNB 반 목록, 서브탭 숨김, 검사 전체 현황

8. GNB [상담·코칭] 클릭
   → 상담·코칭 전체 현황, LNB 반 목록

9. 로고 클릭
   → 홈 화면
```
