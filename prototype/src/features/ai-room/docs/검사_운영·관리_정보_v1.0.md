## 1. 검사 진행 — 시작·종료·취소·재시작

- **시작**: 교사가 회차(1차/2차)·검사 종류를 지정해 검사를 시작하면 대상 학생에게 검사가 배정됩니다. 진행할 활성 학생이 없거나 이미 진행 중인 검사가 있으면 시작할 수 없습니다. 시작 시 대상 학생에게 '검사 배정' 알림이 발송됩니다.
  - **2차(2회차)는 동일 학급에서 1차 응시 이력이 있는 학생만** 출제됩니다. 진입 직전 **사전 검증**으로 출제 가능(ELIGIBLE) / 타학급에서 진행 중(BLOCKED) / 1차 이력 없음(NO_HISTORY)을 분류해 대상 인원을 미리 확인할 수 있습니다.
- **종료**: 교사가 검사를 종료하면 채점이 확정됩니다. 종료 시점에 **문항을 모두 푼 학생은 제출 버튼을 누르지 않았어도 자동 제출·채점**되며, 연속 동일 응답(10문항 이상) 여부도 함께 점검됩니다. 종료와 동시에 리포트 생성 알림(교사)과 결과 공개 알림(학생)이 발송됩니다.
- **취소**: 진행 중 검사를 취소하면 해당 회차의 응답·결과 데이터가 **완전히 삭제**됩니다. 다시 실시하려면 검사를 새로 시작해야 합니다.
- **재시작**: 종료된 검사를 재시작하면 **아직 검사를 받지 못한(신규) 학생에게만 추가 배부**되고, 대상 학생에게 재응시 요청 알림이 발송됩니다. 재시작 시 상태값·기존 PDF는 초기화됩니다.
- **학생 개인 '새로하기'**: 학생이 재접속해 응답을 새로 시작하면 기존 답안이 삭제되고 새로 응시합니다. '이어하기'로 중단 지점부터 계속할 수도 있습니다.

## 2. 결과 채점·확정·공개 시점

- **채점은 학생 제출 시점**에 이뤄집니다(제출 시 채점 + LPA 분류 완료, 학생에게 결과 메일 발송).
- 그러나 **교사·학급 단위 결과의 확정·공개는 교사가 검사를 '종료'할 때** 이뤄집니다. 종료 시 리포트 생성(교사 알림)과 결과 공개(학생 알림)가 함께 발생합니다.
- **결과 공개는 종료 시 자동**이며, 별도의 수동 공개 버튼은 없습니다.
- 별도의 마감일 자동 집계 배치는 없으며, 제출/종료 시점에 즉시 처리됩니다.

## 3. 미응시·미제출 학생 처리

- 검사관리에서 회차별 **전체 / 제출 / 미제출** 인원과 미제출 학생 명단을 확인할 수 있습니다. 상태는 미응시 / 응시중 / 완료로 구분됩니다.
- 검사를 종료하면 미제출 학생은 더 이상 제출할 수 없고 채점 대상에서 제외됩니다(단, 문항을 모두 푼 학생은 자동 제출 처리).
- **미제출 학생 자동 독려(리마인더) 알림은 아직 구현되어 있지 않습니다.** 현재는 교사가 명단을 보고 수동으로 독려합니다.

## 4. 그룹(반)·멤버 관리

- **그룹(반) 생성·수정·삭제·초대·합류 관리는 SSO(mypage)로 이관**되었습니다. 본 서비스(앱)는 그룹을 **조회**하고 그 반에서 **검사를 진행**하는 역할을 담당하며, 그룹 정보는 조회 시 자동 동기화됩니다.
- **초대 코드는 6자리**(영문+숫자, 테넌트 내 고유)입니다.
- **이메일 초대**는 방장 전용이며 **7일간 유효**합니다. 가입 시 대기 중 초대는 자동 합류됩니다.
- 멤버 상태: 활성 / 탈퇴 / 추방 / 보관. 그룹 수정·삭제·강퇴는 **방장 전용**, 탈퇴는 본인만.
- **교사는 학생 멤버로 합류할 수 없습니다**(권한 분리).
- 학급 명단은 **검사 미배정·미제출 학생까지 포함**해 조회할 수 있습니다.

## 5. 엑셀(오프라인) 응답 일괄 등록

- 응답 입력용 **샘플 엑셀**(학생 목록 + 응답 입력란)을 내려받아 오프라인으로 채운 뒤 업로드할 수 있습니다.
- **엑셀 일괄 업로드** 시 유효성 검증에 실패하면 전체 롤백되며, 성공하면 응답값이 반영되고 **검사가 종료 처리**됩니다.

## 6. 리포트·PDF 산출

- 개별 학생 PDF와 전체 일괄(ZIP) 다운로드를 지원합니다. 다운로드 타입은 **상세 보고서 / 요약 보고서 / 상세+요약**으로 구분됩니다.
- 교사용·학생용 PDF가 생성되며, 신뢰도 부족 학생은 별도 분기 처리됩니다.
- 전체 ZIP은 미생성 학생을 조회해 순차 생성한 뒤 묶어 받는 방식이며 이어받기를 지원합니다.
- '학급용 리포트'라는 별도 산출물 구분은 명시되어 있지 않고, 교사용/학생용 + 상세/요약 타입만 확인됩니다.

## 7. 알림(Notification)

- **교사 대상**: 학생 제출, 전원 제출 완료, 검사 종료·리포트 생성.
- **학생 대상**: 검사 배정, 결과 공개, 재응시 요청.
- **그룹 계열**: 가입 / 탈퇴 / 추방 등.
- 알림은 검사 제출·종료 등 트랜잭션 완료 후 발생하며, 실시간(SSE)으로 전달되고 목록·읽음·안읽음 개수 조회가 가능합니다. 90일 경과 알림은 매일 자동 삭제됩니다.
- **미제출 리마인더 알림은 미구현**입니다(§3 참고).

## 8. 신뢰도 '주의' 학생의 운영 처리

- 신뢰도 3지표(반응일관성 · 사회적바람직성 · 연속동일반응) 중 하나라도 '주의'면 결과 해석에 유의가 필요하며, **학급 평균 산정에서 제외**하는 것이 원칙입니다(신뢰 학생이 0명이면 전체로 대체).
- **원칙상 어느 화면에서 보든 학급 평균은 '주의' 학생을 동일하게 제외해 계산해야 합니다.** 다만 현재는 대시보드 화면에서만 이 제외가 적용되고, 챗봇의 학급 평균 조회는 완료 학생 전체 평균을 반환해 **두 값이 달라질 수 있습니다.** 이는 산정 로직이 위치별로 정렬되지 않은 불일치이므로, **챗봇 집계도 대시보드와 동일 기준(주의 제외)으로 맞추는 것이 바람직합니다.**

## 9. 타학급 응시(N:N) 처리

- 한 학생이 여러 학급에 속할 수 있어, 다른 학급에서 응시한 학생은 현재 학급 화면에서 **타학급(OTHER_CLASS) 출처**로 표시되며 본 학급(IN_CLASS)과 구분됩니다.
- 2차 출제 자격도 타학급 이력을 고려해 판정합니다(동일 학급 1차 이력 필요).

## 10. 권한·역할

- **교사**: 검사 관리(시작/종료/취소/재시작), 대시보드, AI Room, 상담 관리, 리포트 다운로드.
- **학생**: 검사 응시, 개인 결과 조회.
- 그룹 수정·삭제·강퇴·초대는 **방장 전용**, 탈퇴는 본인만.
- 교사 식별자는 인증 토큰에서만 도출해 타인 데이터 접근을 방지합니다.

## 11. 검사 소요 시간

- **표준 소요 시간·제한 시간(타이머)에 대한 정의가 없습니다.** 구성은 학습종합검사 124문항, 자기조절학습검사 약 77~80문항(문항 수 기준)뿐이며, 정확한 예상 소요 시간은 별도 운영 안내가 필요합니다.

## 12. 수업자료실 / 콘텐츠 추천

- 수업자료실의 콘텐츠 추천 기준 · 활용 순서 · 운영 방침에 대한 확정 문서/데이터가 없습니다. 챗봇 데이터·Tool에도 포함되지 않습니다.
- **일반 원칙(참고)**: 검사 결과의 약점 영역·학습유형에 맞는 콘텐츠를 골라 활용하고(전량 사용 불필요), 활용 후 관찰·상담·코칭으로 연계하며 2차 검사로 변화를 확인합니다. 구체 추천 로직·순서·사후 리포트는 미확정이므로 "화면 안내 참고" 또는 "아직 데이터로 확인 불가"로 안내하는 것을 권장합니다.
