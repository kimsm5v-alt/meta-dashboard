## 1. 서비스 개요

### 1.1 서비스 목적

META 대시보드는 학습심리정서검사 결과를 분석하여 교사에게 학생 맞춤형 코칭 전략을 제공하고, AI 기반 인사이트를 통해 효과적인 학급 운영을 지원하는 서비스입니다.

### 1.2 핵심 가치

| 가치 | 설명 |
|------|------|
| **개인화** | LPA 유형 분류 기반 학생 맞춤형 분석 |
| **시각화** | 38개 요인의 직관적인 차트/히트맵 표현 |
| **AI 지원** | Gemini 기반 자동 총평, 생활기록부 문구 생성 |
| **변화 추적** | 1차/2차 검사 결과 비교를 통한 성장 추이 분석 |

### 1.3 대상 학교급

| 학교급 | 학년 | LPA 유형 분류 | 비고 |
|--------|------|---------------|------|
| 초등학교 | 1~6학년 | O (3유형) | 자원소진형, 안전균형형, 몰입자원풍부형 |
| 중학교 | 1~3학년 | O (3유형) | 냉소적무기력형, 정서조절취약형, 자기주도몰입형 |
| 고등학교 | 1~3학년 | X | 영역별 강점/약점 분석만 제공 |

## 3. 검사 체계

### 3.1 검사 종류

| 검사명 | 코드 | 문항수 | 분석 단위 | LPA 유형 |
|--------|------|--------|----------|----------|
| 학습종합검사 | comprehensive | 124문항 | 5대영역, 11중분류, 38요인 | O (초/중) |
| 자기조절학습검사 | selfreg | 80문항 | 3대전략, 6중분류, 20요인 | X |

### 3.2 검사 회차

| 슬롯 | 검사 | 회차 | 선행 조건 |
|------|------|------|----------|
| L1 | 학습종합검사 | 1차 | 없음 |
| L2 | 학습종합검사 | 2차 | L1 완료 |
| S1 | 자기조절학습검사 | 1차 | 없음 |
| S2 | 자기조절학습검사 | 2차 | S1 완료 |

### 3.3 검사 상태

| 상태 | 코드 | 설명 |
|------|------|------|
| 시작 전 | not_started | 검사 미시작 |
| 진행 중 | in_progress | 검사 진행 중 |
| 완료 | completed | 검사 종료 |

### 3.4 학습종합검사 요인 구조 (38개)

#### 5대 대분류

| 대분류 | 성격 | 중분류 | 요인 수 |
|--------|------|--------|---------|
| 자아강점 | 정적(+) | 긍정적자아, 대인관계능력 | 7개 |
| 학습디딤돌 | 정적(+) | 메타인지, 학습기술, 지지적관계 | 12개 |
| 긍정적공부마음 | 정적(+) | 학업열의, 성장력 | 6개 |
| 학습걸림돌 | 부적(-) | 학업스트레스, 학습방해물, 학업관계스트레스 | 10개 |
| 부정적공부마음 | 부적(-) | 학업소진 | 3개 |

#### 11개 중분류 및 38개 요인

| 대분류 | 중분류 | 요인 |
|--------|--------|------|
| 자아강점 | 긍정적자아 | 자아존중감, 자기효능감, 성장마인드셋 |
| 자아강점 | 대인관계능력 | 자기정서인식, 자기정서조절, 타인정서인식, 타인공감능력 |
| 학습디딤돌 | 메타인지 | 계획능력, 점검능력, 조절능력 |
| 학습디딤돌 | 학습기술 | 공부환경, 시간관리, 수업태도, 노트하기, 시험준비 |
| 학습디딤돌 | 지지적관계 | 부모의사소통, 부모학업지지, 친구정서지지, 교사정서지지 |
| 긍정적공부마음 | 학업열의 | 활기, 몰두, 의미감 |
| 긍정적공부마음 | 성장력 | 자율성, 유능성, 관계성 |
| 학습걸림돌 | 학업스트레스 | 성적부담, 공부부담, 수업부담 |
| 학습걸림돌 | 학습방해물 | 스마트폰의존, 게임과몰입 |
| 학습걸림돌 | 학업관계스트레스 | 부모성적압력, 부모공부부담, 친구공부비교, 교사성적압력, 교사수업부담 |
| 부정적공부마음 | 학업소진 | 고갈, 무능감, 반감냉소 |

### 3.5 T점수 체계

| 범위 | 해석 | 정적요인 | 부적요인 |
|------|------|----------|----------|
| 20~29 | 매우 낮음 | 주의 필요 | 양호 |
| 30~39 | 낮음 | 주의 필요 | 양호 |
| 40~59 | 평균 | 보통 | 보통 |
| 60~69 | 높음 | 양호 | 주의 필요 |
| 70~80 | 매우 높음 | 양호 | 주의 필요 |

**관심 필요 기준**:
- 정적 요인(긍정): T ≤ 39 → 낮음 주의
- 부적 요인(부정): T ≥ 60 → 높음 주의

## 4. 기능 요건

### 4.1 검사 관리 (교사)

#### FR-ASM-001: 그룹(반) 관리

| 항목 | 내용 |
|------|------|
| **기능명** | 그룹 생성/수정/삭제 |
| **설명** | 교사가 담당 학급(그룹)을 생성하고 관리 |
| **입력** | 학교명, 학교급, 학년, 반, 그룹명 |
| **출력** | 그룹 ID, 초대 코드 (4자리) |
| **비즈니스 규칙** | - 초대 코드는 자동 생성 (영문+숫자 4자리)<br>- 그룹당 최대 학생 수 제한 없음 |

#### FR-ASM-002: 멤버 초대

| 항목 | 내용 |
|------|------|
| **기능명** | 학생 초대 |
| **설명** | 초대 코드 또는 이메일로 학생을 그룹에 초대 |
| **입력** | 이메일 주소 또는 초대 코드 공유 |
| **출력** | 초대 링크, QR 코드 |

#### FR-ASM-003: 검사 시작/종료

| 항목 | 내용 |
|------|------|
| **기능명** | 검사 회차 관리 |
| **설명** | 4개 슬롯(L1, S1, L2, S2) 별 검사 시작/종료 |
| **입력** | 그룹 ID, 슬롯 ID |
| **선행 조건** | L2는 L1 완료 후, S2는 S1 완료 후 시작 가능 |
| **출력** | 검사 상태, 제출 현황 (제출/미제출 학생 목록) |

#### Class (학급)

```typescript
interface Class {
  id: string;
  schoolLevel: '초등' | '중등';
```

```typescript
interface Student {
```

#### Assessment (검사 결과)

```typescript
interface Assessment {
  id: string;
  studentId: string;
  round: 1 | 2;
  assessedAt: Date;
  tScores: number[];              // 38개 요인별 T점수
  predictedType: StudentType;     // LPA 유형
  typeConfidence: number;         // 유형 확신도 (0-100)
  typeProbabilities: Record<string, number>;  // 유형별 확률

  reliabilityWarnings: string[];  // 신뢰도 경고
  attentionResult: AttentionResult;  // 관심 필요 판별
}
```

## 6. 비즈니스 로직

### 6.1 LPA 유형 분류 알고리즘

#### 개요
베이지안 분류기를 사용하여 38개 요인의 T점수 패턴을 분석하고, 학생을 3가지 유형 중 하나로 분류합니다.

#### 분류 수식

```
P(Type|TScores) ∝ P(TScores|Type) × P(Type)

여기서:
- P(TScores|Type): 로그 우도 (Log Likelihood)
- P(Type): 사전확률 (Prior)
```

#### 로그 우도 계산

```
logLikelihood = Σ[-0.5 × ((T_i - μ_type_i)² / σ²_type_i)]

여기서:
- T_i: 학생의 i번째 요인 T점수
- μ_type_i: 해당 유형의 i번째 요인 평균
- σ²_type_i: 해당 유형의 i번째 요인 분산
```

#### 사전확률 (Prior)

| 학교급 | 유형 | 사전확률 |
|--------|------|----------|
| 초등 | 자원소진형 | 30.55% |
| 초등 | 안전균형형 | 35.47% |
| 초등 | 몰입자원풍부형 | 33.98% |
| 중등 | 냉소적무기력형 | 35.4% |
| 중등 | 정서조절취약형 | 26.6% |
| 중등 | 자기주도몰입형 | 38.1% |

### 6.2 관심 필요 판별 알고리즘

#### 판별 기준

| 요인 성격 | 조건 | 결과 |
|----------|------|------|
| 정적 요인 (긍정) | T ≤ 39 | 관심 필요 (낮음 주의) |
| 부적 요인 (부정) | T ≥ 60 | 관심 필요 (높음 주의) |

#### 출력 형식

```typescript
interface AttentionResult {
  needsAttention: boolean;
  reasons: AttentionReason[];
}

interface AttentionReason {
  category: FactorCategory;      // 5대 영역
  factors: { name: string; score: number }[];
  direction: 'low' | 'high';
}
```

### 6.3 개입 전략 랭킹 알고리즘

#### 점수 계산 공식

```
relevanceScore = needScore × 0.5 + deviationScore × 0.3 + betaBoost × 0.2

여기서:
- needScore: 이상 방향 편차 점수 (0-100)
- deviationScore: 유형 평균 대비 편차 점수 (0-100)
- betaBoost: 통계적 효과크기 점수 (0-100)
```

#### needScore 계산

```
정적 요인: max(0, 50 - T점수) / 30 × 100
부적 요인: max(0, T점수 - 50) / 30 × 100
```

#### deviationScore 계산

```
|T점수 - 유형평균| × 가중치 / 15 × 100

가중치:
- 나쁜 방향 편차: 1.5배
- 좋은 방향 편차: 0.5배
```

### 6.4 신뢰도 검증

#### 신뢰도 경고 유형

| 경고 | 설명 | 판별 기준 |
|------|------|----------|
| 반응일관성 | 유사 문항 간 일관성 부족 | 내부 일관성 계수 기준 미달 |
| 사회적바람직성 | 긍정적 이미지 과장 응답 | 사회적 바람직성 척도 기준 초과 |
| 연속동일반응 | 동일 응답 연속 선택 | 연속 동일 응답 개수 기준 초과 |
