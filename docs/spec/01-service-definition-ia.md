# 1. 서비스 정의 & IA

> **META 학습심리정서검사 AI 에이전트 플랫폼**  
> 최종 수정일: 2026-03-11

---

## 1. 서비스 개요

META 학습심리정서검사의 시행부터 결과 분석까지 지원하며, AI 기반 해석과 맞춤형 코칭 전략 수립을 통해 교사의 학생 지도를 돕는 웹 플랫폼.

### 핵심 가치

| 가치 | 설명 |
|------|------|
| 직관적 시각화 | 38개 요인 → 11개 중분류 → 5대 영역을 계층적 대시보드로 시각화 |
| AI 기반 해석 | Gemini AI가 검사 결과를 3줄 요약, 코칭 제안으로 변환 |
| 다층 분석 | 전체 반(L1) → 학급(L2) → 학생(L3) 드릴다운 |
| 업무 통합 | 생활기록부 문구, 상담 기록, 관찰 메모를 하나의 플랫폼에서 처리 |
| SEL 교육 연결 | 학습심리 진단 데이터를 기반으로 학생·학급별 SEL 활동을 추천하고 효과를 추적 |
| 실행 자료 연결 | 유형별 활동지, SEL 수업 자료, 상담 템플릿을 태그 기반으로 큐레이션 |
| 커뮤니티 | 지도 사례·SEL 수업 후기를 공유하고, 교사 간 노하우를 축적 |

### 대상 사용자

| 사용자 | 역할 |
|--------|------|
| 담임교사 (주 사용자) | 검사 관리, 결과 분석, 상담 기록, AI 활용 |
| 학생 | 검사 응시 (QR 코드 → 비회원 가능) |
| 관리자 (향후) | 학교 단위 현황 조회 |

## 2. 도메인 지식

### META 검사 구조

```
38개 세부 요인 (T점수: 20~80, 평균 50, 표준편차 10)
  ↓ 그룹핑
11개 중분류
  ↓ 그룹핑
5대 영역
  ├── 자아강점 (정적)        → 긍정적 자아, 대인관계능력
  ├── 학습디딤돌 (정적)      → 메타인지, 학습기술, 지지적 관계
  ├── 학습걸림돌 (부적)      → 학업스트레스, 학업관계 스트레스, 학습 방해물
  ├── 긍정적공부마음 (정적)   → 학업열의, 성장력
  └── 부정적공부마음 (부적)   → 학업소진
```

- **정적 요인**: 점수↑ = 긍정적
- **부적 요인**: 점수↑ = 부정적
- **차수**: 연 2회 실시 (1차: 3월, 2차: 9월)

### LPA 유형 분류

38개 T점수 패턴으로 3개 유형 자동 분류 (Latent Profile Analysis). 초등/중등 별도 모델.

| 학교급 | 유형 1 | 유형 2 | 유형 3 |
|--------|--------|--------|--------|
| 초등 | 자원소진형 (30.6%) | 안전균형형 (35.5%) | 몰입자원풍부형 (34.0%) |
| 중등 | 무기력형 (35.4%) | 정서조절취약형 (38.0%) | 자기주도몰입형 (26.6%) |

### 관심 필요 학생 판별

| 요인 유형 | 기준 | 의미 |
|-----------|------|------|
| 정적 요인 (isPositive=true) | T점수 ≤ 39 | 긍정 자원이 현저히 부족 |
| 부적 요인 (isPositive=false) | T점수 ≥ 60 | 부정 요인이 현저히 높음 |

## 3. 용어 정리

| 용어 | 설명 |
|------|------|
| T점수 | 평균 50, 표준편차 10 기준 표준화 점수 (20~80) |
| LPA | Latent Profile Analysis — 잠재프로파일분석 |
| 중분류 | 38개 요인을 묶은 11개 상위 카테고리 |
| 5대 영역 | 자아강점, 학습디딤돌, 학습걸림돌, 긍정적공부마음, 부정적공부마음 |
| 차수 (round) | 연 2회 실시 (1차: 3월, 2차: 9월) |
| dgnssId | 기존 AIDT 시스템의 검사 세션 ID |
| SECTION_ID | 기존 AIDT의 요인 식별 코드 (`10-22-{대영역}-{중분류}-{소분류}-0`) |
| PII | Personally Identifiable Information — AI 전송 시 마스킹 대상 |

## 4. 정보 구조 (IA)

### 전체 구조

```
META 학습심리정서검사 대시보드
│
├── 🌐 공개 영역 (사이드바 없음)
│   ├── /                        랜딩 페이지
│   ├── /login                   로그인
│   ├── /exam                    검사 코드 입력
│   ├── /exam/:code              학생 검사 응시
│   └── /join/:code              그룹 가입 (초대 코드)
│
└── 🔒 보호 영역 (사이드바 있음, 로그인 필요)
    │
    ├── 📋 검사
    │   ├── /groups                              그룹 관리 (목록)
    │   │   └── /groups/:groupId                 └─ 그룹 상세
    │   ├── /assessment                          검사하기
    │   └── /dashboard                           L1: 교사 전체 반 대시보드
    │       └── /dashboard/class/:classId                L2: 반별 대시보드
    │           ├── /dashboard/class/:classId/analysis   L2.5: 학급 상세 분석
    │           └── /dashboard/class/:classId/student/:studentId  L3: 학생 대시보드
    │
    ├── 💬 상담
    │   ├── /schedule                            상담일정 (캘린더)
    │   └── /counseling-dashboard                상담 대시보드
    │
    ├── 📚 콘텐츠
    │   ├── /resources                           교육 자료실
    │   │   └── /resources/:resourceId           └─ 자료 상세
    │   └── /community                           교사 커뮤니티
    │       ├── /community/write                 └─ 글 작성
    │       └── /community/:postId               └─ 글 상세
    │
    └── 🤖 AI
        └── /ai-room                             AI 어시스턴트
```

### LNB (사이드바) 메뉴

| 그룹 | 메뉴명 | 경로 | 구현 상태 |
|------|--------|------|----------|
| 검사 | 그룹 관리 | `/groups` | ✅ |
| 검사 | 검사하기 | `/assessment` | ✅ |
| 검사 | 대시보드 | `/dashboard` | ✅ |
| 상담 | 상담일정 | `/schedule` | ✅ |
| 상담 | 상담 대시보드 | `/counseling-dashboard` | 🔲 Phase 2 |
| 콘텐츠 | 교육 자료실 | `/resources` | 🔲 Phase 2 |
| 콘텐츠 | 교사 커뮤니티 | `/community` | 🔲 Phase 2 |
| AI | AI 어시스턴트 | `/ai-room` | ✅ |

### 대시보드 계층

```
L1: 교사 전체 반 대시보드 (/dashboard)
 │  클릭: 반 카드
 ▼
L2: 반별 대시보드 (/dashboard/class/:classId)
 │
 ├── "상세 분석" 버튼 → L2.5: 학급 상세 분석 (/dashboard/class/:classId/analysis)
 │
 └── 학생 행 클릭 → L3: 학생 대시보드 (/dashboard/class/:classId/student/:studentId)
```

### 레이아웃

| 레이아웃 | 사용 영역 | 특징 |
|----------|----------|------|
| MinimalLayout | 공개 라우트 (/, /login, /exam, /join) | 사이드바 없음 |
| Layout | 보호 라우트 (로그인 후 전체) | LNB 사이드바 + 헤더 |

## 5. 시스템 구성

### 현재 상태

| 구분 | 상태 | 비고 |
|------|------|------|
| 프론트엔드 | ✅ 구현 완료 | React + TypeScript + Vite |
| 기존 백엔드 (AIDT) | ✅ 운영 중 | 검사 CRUD, T점수 조회, 학급 분석 |
