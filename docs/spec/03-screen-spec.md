#### 기능

| # | 기능 | 설명 |
|---|------|------|
| 1 | 문항 표시 | 125문항 페이지네이션 (20문항/페이지) |
| 2 | 답안 선택 | 리커트 5점 척도 (1~5) |
| 3 | 답안 실시간 저장 | 문항 선택 즉시 서버 저장 |
| 4 | 진행률 표시 | 전체 125문항 대비 응답 수 |
| 5 | 답안 초기화 | 전체 답안 리셋 |
| 6 | 검사 제출 | 전체 응답 완료 후 제출 |

#### 데이터

| 구분 | 내용 |
|------|------|
| 표시 데이터 | 문항 텍스트 (QESITM_NM), 문항 번호 (NO), 전체 문항 수 (fullCount), 기존 답변 (answer) |
| 사용자 입력 | 각 문항별 답변 (1~5) |
| 핵심 ID | `dgnssResultId` (학생별 결과 ID), `omrIdx` (OMR 인덱스) |

#### API

| # | 메서드 | 엔드포인트 | 구분 | 설명 |
|---|--------|-----------|------|------|
| 1 | GET | `/etc/meta/st/info` | 🔵 기존 | 검사 목록 조회 → dgnssResultId 획득 |
| 2 | GET | `/etc/meta/st/start` | 🔵 기존 | 문항 로드 (페이지별) → omrIdx 획득 |
| 3 | POST | `/etc/meta/st/answer` | 🔵 기존 | 답안 저장 (omrIdx + no + answer) |
| 4 | GET | `/etc/meta/st/new` | 🔵 기존 | 답안 초기화 |
| 5 | POST | `/etc/meta/st/submit` | 🔵 기존 | 검사 제출 (dgnssResultId) |

**🟢 신규 API 상세 — POST /api/groups/join**

요청 (회원):
```json
{
  "inviteCode": "ABC123"
}
```

요청 (게스트):
```json
{
  "inviteCode": "ABC123",
  "isGuest": true
}
```

응답:
```json
{
  "groupId": "uuid-...",
  "groupName": "6학년 2반",
  "studentId": "auto-generated"
}
```

비즈니스 룰:
- 회원 로그인 → JWT에서 studentId 추출, 기존 회원 정보 연동
- 게스트 로그인 → `studentId` 서버 자동 생성, `isGuest = true`
