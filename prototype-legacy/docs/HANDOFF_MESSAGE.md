## 💬 구두 설명용 (미팅 시)

### 1분 버전
```
고등학교는 LPA 유형이 없어서, 학교급 체크해서 자동으로 UI 바뀌게 했어요.
초/중등은 "몰입자원 풍부형" 같은 유형 배지 나오고,
고등은 "자아존중감", "성장마인드셋" 같은 강점 태그로 나와요.
총 4개 파일 수정했고, 상세 문서 작성해뒀습니다.
```

### 3분 버전
```
배경:
- 초등/중등은 LPA 유형 3개로 분류 (자원소진형, 안전균형형, 몰입자원풍부형)
- 고등학교는 LPA 유형 분류 자체가 없음 (연구 설계상 없음)
- 고등은 영역별 강점/약점만 표시해야 함

구현 방식:
- hasLPA를 학교급에 따라 동적 계산
- 학습종합검사 + 고등 = hasLPA: false 처리
- hasLPA가 false면 기존에 이미 구현된 "강점/관심 요인" UI로 자동 전환

수정 위치:
1. 학생 대시보드: 학습 유형 분류 섹션, 유형별 특이점 섹션
2. 학급 대시보드: KPI 카드, 유형 분포 차트, 학생 목록
3. 전체 반 대시보드: 우측 패널 유형 분포, LPA 비교 섹션

참고:
- HSJ_Dashboard 핸드오프 디자인 기반으로 구현
- 자기조절검사는 원래부터 LPA 없어서 영향 없음
- 기존 초/중등 데이터는 그대로 작동
```

## 📋 Q&A 예상 질문

**Q: 왜 고등학교는 LPA가 없나요?**
A: 연구 설계상 초등/중등만 LPA 유형 분류 모델이 개발되었습니다. 고등은 영역별 분석만 제공합니다.

**Q: 기존 데이터에 영향 있나요?**
A: 없습니다. 초등/중등 데이터는 기존과 동일하게 작동하고, 고등 데이터만 다르게 표시됩니다.

**Q: 추가 작업 필요한가요?**
A: 코드 리뷰와 테스트만 부탁드립니다. 누락된 화면 있으면 말씀해주세요.

**Q: 디자인 변경 필요한가요?**
A: 아니요. 기존에 이미 구현된 "강점/관심" UI를 재사용합니다.

**Q: 백엔드 API 변경 필요한가요?**
A: 아니요. 학교급 정보는 이미 API에서 내려오고 있습니다.
