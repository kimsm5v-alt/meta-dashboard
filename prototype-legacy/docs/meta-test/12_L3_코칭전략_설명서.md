# L3 코칭 전략 — 기술 설명서

> L3(학생 대시보드)의 "코칭 전략" 모달은 학생의 LPA 유형과 38개 T점수를 기반으로
> **개인화된 코칭 경로**를 관련도 순으로 제시하는 기능입니다.

---

## 1. 전체 구조

```
[학생의 38개 T점수] + [LPA 유형]
        ↓
  interventionRanker.ts ← 10_지식그래프.json (MediationPath + ModerationPath)
        ↓
  관련도 점수 산출 → 정렬
        ↓
  CoachingStrategy.tsx (Top 5 표시 + 더보기)
```

| 레이어 | 파일 | 역할 |
|--------|------|------|
| 데이터 | `10_지식그래프.json` | 초등/중등 그래프: 노드 159개씩, 링크 582/581개 |
| 로직 | `interventionRanker.ts` | 관련도 점수 산출 + 정렬 |
| UI | `CoachingStrategy.tsx` | 모달 표시, Top 5 + 더보기 |

## 2. 지식그래프 노드 구조

지식그래프(`10_지식그래프.json`)는 **3종류의 노드**로 구성됩니다.

| 노드 유형 | 타입 | 개수(초등/중등) | 역할 |
|-----------|------|:---:|------|
| 결과변수 | `Outcome` | 1 | 학업성취도 (코칭의 최종 목표) |
| LPA 유형 | `LPAClass` | 3 | 유형별 핵심특성, 비율, 심리상태, 설명 |
| 요인 | `Factor` | 38 | 38개 심리-학습 요인의 메타데이터 |
| | **합계** | **42** | (+ 추가 메타노드 포함 시 159개) |

## 3. 코칭 경로 유형

노드 간 관계를 정의하는 **2가지 경로 유형**이 있습니다.

### 3.1 MediationPath (매개경로)

X → M → Y 형태의 순차적 매개 경로입니다.

```typescript
interface MediationPath {
  type: "MediationPath";
  lpa_class: string;           // 적용 유형
  x: string | null;            // 독립변수 (null이면 direct)
  m: string;                   // 매개변수
  y: string;                   // 결과변수
  path_type: "완전매개" | "mediation" | "direct";
  interpretation: string;      // 경로 해석 (교사용)
  strategy: string;            // 코칭 전략
  id: string;                  // 고유 ID
}
```

**path_type 설명**:
- `완전매개`: X가 M을 경유해야만 Y에 영향
- `mediation`: 일반 매개 경로
- `direct`: X 없이 M → Y 직접 경로

### 3.2 ModerationPath (조절경로)

X × Z → Y 형태의 상호작용 경로입니다.

```typescript
interface ModerationPath {
  type: "ModerationPath";
  lpa_class: string;           // 적용 유형
  x: string;                   // 독립변수
  z: string;                   // 조절변수
  y: string;                   // 결과변수
  path_type: PathType;         // 조절효과 유형
  path_color: string;          // 시각화 색상
  keyword_interp: string;      // 해석 키워드
  keyword_strat: string;       // 전략 키워드
  interpretation: string;      // 경로 해석
  strategy: string;            // 코칭 전략
  z_factor_type: "positive" | "negative";
  z_need_direction: "lower_T_worse" | "higher_T_worse";
  id: string;                  // 고유 ID
}
```

### 3.3 조절효과 유형 (PathType) 7종

| path_type | 의미 | path_color | 설명 |
|-----------|------|------------|------|
| 촉진 | Z가 X의 효과를 증폭 | #3498DB (파랑) | Z 수준에 따라 X→Y 효과가 증폭 |
| 억제 | Z가 X의 효과를 감소 | #E74C3C (빨강) | Z 수준에 따라 X→Y 효과가 억제 |
| 긍정 완충 | X 부족 시 Z가 보호 | #27AE60 (초록) | 부정적 영향을 완화하는 보호요인 |
| 부정 완충 | X와 Z 동시 약화 시 악화 | #E67E22 (주황) | 취약요인 간 결합으로 악화 |
| 긍정 강화 | X × Z 시너지 효과 | #2ECC71 (연두) | 두 요인이 결합하여 시너지 발생 |
| 부정 강화 | X × Z 부정적 결합 | #C0392B (진빨강) | 두 요인이 결합하여 부정적 효과 |
| 조합 | 복합적 상호작용 | #95A5A6 (회색) | 단순 분류가 어려운 복합 효과 |

## 4. 관련도(Relevance Score)란?

**관련도**는 특정 코칭 경로가 **이 학생에게 얼마나 시급하고 적합한지**를 0~100 사이 점수로 나타낸 것입니다.
같은 유형의 학생이라도 38개 T점수 프로필이 다르므로, 관련도 점수와 경로 순위가 달라집니다.

### 4.1 산출 공식

```
관련도 = needScore × 0.6 + deviationScore × 0.4
```

| 요소 | 가중치 | 의미 | 산출 방법 |
|------|:---:|------|------|
| **needScore** | 60% | 개입 필요도 | 관련 요인(X, M, Z)의 T점수가 이상적 방향에서 벗어난 정도. `need_score_direction` 참조 |
| **deviationScore** | 40% | 유형 내 취약도 | 같은 유형의 평균 T점수 대비 이 학생이 나쁜 방향으로 벗어난 정도 |

### 4.2 UI 표시

| 관련도 범위 | 배지 색상 | 의미 |
|:---:|------|------|
| ≥ 50 | 빨간색 | 이 학생에게 특히 시급한 경로 |
| 25 ~ 49 | 주황색 | 보완이 필요한 경로 |
| < 25 | 회색 | 현재 큰 문제는 아닌 경로 |

### 5.2 초등 자원소진형 (39개)

> 심리자원 낮음, 스트레스 높음. 순차적 자원 구축이 핵심.

**MediationPath (1개)**:
- 유능성 → 성장마인드셋 → 학업성취도 (완전매개)

**ModerationPath 주요 예시**:
| path_type | 경로 | 핵심 메시지 |
|-----------|------|-------------|
| 조합 | 수업태도 × 게임 과몰입 | 집중-휴식 리듬 형성, 즉각보상 대체 |
| 억제 | 스마트폰 의존 × 계획능력 | 계획-실행 간격 축소, 폰 없는 시간 확보 |
| 긍정 강화 | 자기정서인식 × 공부환경 | 환경 맞춤 설계, 정서-환경 연결 |
| 촉진 | 타인공감능력 × 교사 성적압력 | 교사 기대 민감도 활용, 단계적 목표 |

### 5.3 초등 안전 균형형 (39개)

> 전반적 균형이나 점검능력 약함. 성장마인드셋 경유 경로가 핵심.

**MediationPath (1개)**:
- 친구 공부비교 → 조절능력 → 학업성취도 (완전매개)

**ModerationPath 주요 패턴**:
- 메타인지(계획/점검/조절) × 교사정서지지 완충 경로 다수
- 긍정 강화: 자기효능감/자아존중감 × 성장마인드셋

### 5.4 초등 몰입자원 풍부형 (39개)

> 동기 높음, 시험전략 보완 필요. 기존 자원을 활용한 심화가 핵심.

**MediationPath (1개)**:
- 유능성 → 성장마인드셋 → 학업성취도 (완전매개)

**ModerationPath 특징**:
- 이미 자원이 풍부하므로 심화 도전과 시험 전략 보완 중심
- 자기주도적 선택권 부여 경로 강조

### 5.5 중등 냉소적 무기력형 (39개)

> 동기 저하, 무력감. 작은 성공 축적 + 즉각 피드백이 핵심.

**MediationPath (3개)**:
- 성장마인드셋 → 유능성 → 학업성취도 (mediation)
- 수업태도 → 노트하기 → 학업성취도 (mediation)
- [직접] 자기정서조절 → 학업성취도 (direct)

**ModerationPath 주요 패턴**:
- 게임 과몰입/스마트폰 의존 관련 억제 경로
- 교사정서지지 촉진/완충 경로

### 5.6 중등 정서조절 취약형 (39개)

> 스트레스 관리 미흡, 감정 기복. 정서 안정 후 성장 관점 전환이 핵심.

**MediationPath (1개)**:
- 수업태도 → 노트하기 → 학업성취도 (mediation)

**ModerationPath 특징**:
- 부모 성적압력/공부부담 관련 완충 경로
- 정서 안정을 우선시하는 전략 강조

### 5.7 중등 자기주도 몰입형 (39개)

> 자율적 학습, 높은 성취동기. 사회적 역량 강화가 핵심.

**MediationPath (1개)**:
- [직접] 자기정서조절 → 학업성취도 (direct)

**ModerationPath 특징**:
- 긍정 강화 경로가 많음 (자원 간 시너지)
- 또래 멘토링, 협력학습 구조 활용 전략

## 6. interpretation과 strategy 필드

각 경로에는 `interpretation`(해석)과 `strategy`(전략) 필드가 포함됩니다.

### 6.1 interpretation (경로 해석)

교사가 이해할 수 있는 언어로 경로의 의미를 설명합니다.

**작성 원칙**:
| 원칙 | 설명 |
|------|------|
| 유형 특성 반영 | "자원소진형 학생은..." 처럼 유형 맥락 포함 |
| 경향성 표현 | "~하는 경향이 있습니다", "~하기 쉬운 편입니다" |
| 메커니즘 설명 | X→Y로 가는 이유와 Z의 역할 설명 |

**예시** (자원소진형, 게임 과몰입 조합):
```
"게임 과몰입이 낮을수록 수업태도가 높아지는 경향을 보입니다.
자원소진형은 게임이 즉각 보상·도피가 되기 쉬운 편이어서,
과몰입이 올라가면 수업에서의 지속과 회복이 어려워질 수 있습니다."
```

### 6.2 strategy (코칭 전략)

교사가 바로 실행할 수 있는 구체적인 행동 지침입니다.

**작성 원칙**:
| 원칙 | 설명 |
|------|------|
| 즉시 실행 가능 | 내일 바로 시도할 수 있는 행동 |
| 구체적 예시 포함 | "15-3, 25-5 리듬" 처럼 숫자나 구체적 방법 |
| 유형 맞춤 | 같은 경로라도 유형에 따라 전략 차별화 |

**예시** (자원소진형, 게임 과몰입 조합):
```
"교실에서는 '집중-휴식 리듬'을 고정합니다(15-3, 25-5 등)
즉각보상 욕구를 예측 가능한 휴식으로 대체합니다.
가정 연계가 가능하면 '해야 할 것 완료→정해진 시간만' 조건부 구조를 제시합니다."
```

## 7. keyword_interp와 keyword_strat

ModerationPath에는 핵심 키워드 필드가 있습니다.

| 필드 | 설명 | 예시 |
|------|------|------|
| `keyword_interp` | 해석 핵심 키워드 (짧은 요약) | "즉각 보상이 계획 무력화" |
| `keyword_strat` | 전략 핵심 키워드 (짧은 요약) | "계획-실행 간격 축소, 폰 없는 계획 시간" |

> 일부 경로(path_type="조합")는 keyword가 빈 문자열일 수 있습니다.

## 8. Top 5 표시 + 더보기 UI

```json
{
```
