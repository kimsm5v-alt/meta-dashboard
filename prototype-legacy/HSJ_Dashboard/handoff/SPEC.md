## 0. 교체 범위

### LNB(좌측 내비) 변경 — ⚠ 결과보기 외 영역이지만 함께 반영 필요

        └─ 자기조절학습검사

- **교체 대상**: 결과보기(대시보드) 영역만 — `전체 보기 → 반 결과 → 학생 상세`

## 1. 데이터 계약 (가장 중요)

목업의 mock 생성기(`window.HSJ_DATA`)는 버리되, **`FACTOR_MODEL` 구조는 데이터 계약의 기준**으로 삼으세요.

```
FACTOR_MODEL[testId] = {
  id, name, shortName, color, colorSoft, colorMid,
  hasLPAType: boolean,              // 고등 학습종합검사 = false
  areas: [                          // 대분류(1뎁스)
    {
      id, name, color, colorSoft,
      polarity: 'positive' | 'negative',   // negative = 낮을수록 좋음
      categories: [                 // 중분류(2뎁스)
        { id, name, factors: [ { id, name } ] }   // 소분류(3뎁스)
      ]
    }
  ],
  lpaTypes: [ { id, name, color, colorSoft } ]    // hasLPAType=false면 빈 배열
}
```

- **학습종합검사**: 5대 영역 / 11중분류 / 38소분류, 정·부적 혼재, LPA 있음(초·중등)
  - 정적: 자아강점·학습디딤돌·긍정적공부마음 / 부적: 학습걸림돌·부정적공부마음
- **자기조절학습검사**: 3대 영역(동기·인지·행동전략) / 6중분류 / 20소분류, **전부 정적**, LPA 없음
- 점수는 모두 **T점수**(전국 평균 50, 표준편차 10 가정). 등급: ~30 매우낮음 / ~40 낮음 / ~60 보통 / ~70 높음 / 그 이상 매우높음
- LPA 유형(초등 3종): 자원소진형(#E74C3C) / 안전균형형(#3498DB) / 몰입자원풍부형(#2ECC71). 중등은 유형명·색이 다름(별도 확인 필요)

### 세션(차수)
- 검사별 연 2회: 1차 / 2차. 검사마다 추천 시기 다름(학습종합 3월·9월 / 자기조절 6월·12월)
- 학생/반은 1차만, 2차만, 둘 다일 수 있음 → **항상 "보유한 차수"를 확인**해서 렌더 분기

### 어댑터 권장
실제 API 응답 → 위 `FACTOR_MODEL` + `classAggregate(class, sessionNo, testId)`(반 평균 T맵) 형태로 변환하는 **어댑터 레이어**를 두면, 차트·정책 로직을 거의 그대로 재사용할 수 있습니다.

## 2. 정책(규칙) — UI와 분리해 함수/상수로

### (a) Polarity 처리
- 부적 영역은 "점수 높음 = 나쁜 신호". 변화량(△)·편차·강약점 분류·색상에서 **방향을 반전**.
- 강점/약점 분류: 정적은 T 높을수록 강점, 부적은 T 낮을수록 강점.

### (b) 신뢰도 주의
- 신뢰도 '주의' 학생은 **반 평균·유형 분포 등 집계에서 제외**.
- 단, **반 응시자 전원이 주의면 부득이 포함**하고 경고 배너 노출.
- 판정 지표 3종: 반응 일관성 / 사회적 바람직성 / 연속 동일 반응 (하나라도 '주의'면 표시).

### (c) 관심 필요 배지
- 평균에서 매우 크게 벗어난 지표 2개 이상, 또는 경계 수준 지표 5개 이상.

### (d) 전체 비교 요약 = 아웃라이어 정책
- 단위: **반 × 영역 셀**. 각 영역의 학년 평균 대비 편차 = (반 점수 − 학년 평균).
- **|편차| ≥ 3**인 셀을 후보로, 의미 방향(정적/부적)에 따라 🔻주의 / 🔺긍정 구분.
- 주의 우선 + |편차| 큰 순 상위 4개. 후보 없으면 편차 상위로 채움(목업은 데모라 항상 채움).

### (e) 임계값(튜닝 포인트, 한 곳에 상수로)
- 아웃라이어 노출: |Δ| ≥ **3**
- 강점/약점: 정적 ≥60 강점 / ≤40 보완, 부적은 반전
- 관심 학생: 위 (c)

## 3. 화면별 동작

### 전체 보기 (A안)
- 헤더: 검사명 태그 · 담당 학급 수 · 총 학생 수 · 전체 리포트 버튼
- 반별 비교 **라인차트**(X축 = N대 영역 / N개 요인 토글). 선·반칩 클릭 시 우측 요약이 그 반으로 전환(다시 클릭 시 전체).
- 우측 **전체 비교 요약** = 아웃라이어 카드(정책 d). 반 선택 시 그 반 요약(평균T·관심영역·(LPA)유형분포)으로 전환.
- 하단(LPA 검사만) **학생 유형 분포 비교**: 반별 1차·2차 LPA 분포 2구역 + 미실시 placeholder.
- selfreg는 LPA 섹션 자동 숨김.

### 반 결과
- 빵부스러기: `결과보기 › {검사명} › {반} 검사 분석`
- 전원 신뢰도 주의 시 경고 배너.
- KPI 4: 학급 평균 점수 / (LPA)우세 유형|(무LPA)대표 강점 영역 / 관심 필요 학생 / 검사 완료율
- 탭 **핵심 요약**: (LPA)유형 분포 도넛(호버·클릭→학생목록 팝오버) + 종합 결과 요약(영역 막대) + 추천 학급 운영 활동(자료 1개+다운로드)
- 탭 **학습 상세**: 강점·약점 TOP3 + 38요인 프로파일(요인 클릭→학생별 T점수 모달) + 영역요약/세부요인 토글
- 탭 **학생 목록**: 카드형. (LPA)1·2차 유형 칩 / (무LPA)최신차수 3뎁스 강점·관심 요인. 필터(전체/신뢰도주의/관심/유형변화) + 배지 기준 안내 모달. 보고서 다운로드 모달(차수·형식·대상, 교사용 종합 보고서 포함).

### 학생 상세
- 빵부스러기: `결과보기 › {검사명} › {반} 검사 분석 › {번호} {이름}`
- 헤더: 이름 + (LPA)유형 칩 + 관심/신뢰도 배지 / 응시일·차수·완료인원 메타 / 이전·다음 학생(N/N) + 보고서 다운로드
- **차수 스위처**: 1차 / 2차 / 차수 변화
  - 차수 변화: 38요인 막대를 1차(연회색)·2차(진회색) 2개 + 등급 라벨, 튀는 구간은 초록/빨강. LPA는 1·2차 도넛 2개.
- AI 분석 총평(데이터 기반 1문장, 기존 AI 기능 연결)
- N개 요인 분석: 영역 탭 + 등급 막대(보통=회색, 정적 높음=초록·낮음=빨강 / 부적 반전), 전국평균 50 점선, 중분류 묶음 구분
- (LPA) 학습 유형 분류(도넛+설명) / 유형별 특이점
- 추천 코칭 전략(아코디언, 자기조절검사엔 없음)
- 우측 플로팅 스피드다이얼(학생 상세에서만): AI챗 / 관찰 / 상담 / 생기부 → 비모달 사이드 패널(메인이 밀려남)

## 4. 주의사항 (반드시 확인)

1. **목업 코드 직접 이식 금지** — Babel-in-browser, 전역 `window.*` 공유, 인라인 스타일·하드코딩 mock은 데모 한정. 프로젝트 컨벤션으로 재작성.
2. **mock 데이터 가정에 의존 금지** — 학교명("서울초등학교"), 응시일("2026.03.15"), 초대코드, 학생 이름 등은 전부 가짜. 실데이터로 대체.
3. **차수 보유 케이스 분기** — 1차만/2차만/둘다/0개 모두 처리(빈 상태·placeholder 포함). mock은 항상 데이터가 있어 놓치기 쉬움.
4. **polarity 반전 누락 주의** — 부적 영역을 정적처럼 처리하면 색·변화·강약점·요약이 전부 틀어짐. 정책 함수로 일원화.
5. **LPA ON/OFF** — `hasLPAType=false`(고등·자기조절)에서 LPA 위젯(유형분포·도넛·우세유형·유형변화)이 빠지고 대체 위젯이 들어가야 함. 조건부 렌더 철저히.
6. **신뢰도 집계 제외 규칙** — 평균 계산에서 제외하되 전원 주의 예외. 통계 함수에 반드시 반영.
7. **개인정보·해석 책임** — 검사 결과는 학생을 단정하지 않는 "참고 신호". 생기부 자동 문구·AI 총평은 교사 검토 전제 문구 유지. 민감정보 접근 권한(교사-담당 학급) 서버에서 검증.
8. **색상 고정값** — 검사·영역·LPA 유형 색은 정해진 HEX. 디자인 토큰에 매핑하되 임의 변경 금지.
9. **성능** — 38요인 × N반 집계는 메모이즈. 차트는 데이터 변경 시에만 재계산.
10. **반응형/접근성** — 1280px 기준 디자인. 막대·도넛 라벨 잘림, 한글 줄바꿈, 색맹 대비(색+아이콘 병행) 점검.
11. **최신 파일만 인계** — 루트의 *.jsx/style.css/HSJ Dashboard.html만. `deploy/`·`deploy-single/`은 옛 사본이라 제외.

## 5. 파일 맵 (목업 참조용)
> **진입 파일 = `HSJ Dashboard.html`** (찐 본 파일, 모든 jsx/css 로드). `index.html`은 배포 번들용 변형이니 핸드오프 기준에서 제외. `deploy/`·`deploy-single/`도 옛 사본이라 제외.

- `data.js` — FACTOR_MODEL 정의 + mock 생성기(구조만 참고, 생성기는 버림) + 집계 헬퍼(`classAggregate`, `classLPADist`, `classifyCompFactor`, `progressOf`, `sessionOf`)
- `page-comp-overview.jsx` — 전체 보기
- `overview-variants.jsx` — A안(CompareOverview) + 요약/지표 변형
- `comp-overview-charts.jsx` — 라인차트·요약 패널·LPA 분포 비교
- `page-comp-class.jsx` — 반 결과(탭·KPI·유형분포·강약점·운영활동·학생목록·모달)
- `page-comp-student.jsx` — 학생 상세(차수 스위처·요인분석·유형분류·코칭)
- `comp-charts.jsx` — 막대/프로파일/도넛/영역 차트
- `drawer-shell.jsx` / `student-drawer.jsx` — 플로팅 스피드다이얼 + 사이드 패널
- `shell.jsx` — LNB·헤더·공통 아이콘·InfoTooltip
- `style.css` — 전체 스타일 + 디자인 토큰(`--test-*`, `--factor-*`, `--lpa-*`)
