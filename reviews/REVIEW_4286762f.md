### Medium (개선 권장)

**1. `completionRate` 계산 시 0으로 나누기 가능성 (방어 코드 부재)**

`totalStats.totalStudents`가 0인 경우 `completionRate`가 `NaN`이 되어 UI에 "NaN%"로 표시될 수 있습니다. 현재 `classes.length === 0`일 때 `NoClassesState`로 조기 반환되므로 실제로는 발생하지 않지만, `classes` 배열에 `totalStudents`가 0인 반만 존재하는 경우(예: 아직 학생이 배정되지 않은 반)에는 여전히 `NaN`이 발생할 수 있습니다.

- **위치**: `TeacherDashboardPage.tsx` 라인 143 (`const completionRate = ...`)
- **기존 코드**:
```tsx
const completionRate = Math.round((totalStats.assessedStudents / totalStats.totalStudents) * 100);
```
- **해결 방안 (수정 코드)**:
```tsx
const completionRate =
  totalStats.totalStudents > 0
    ? Math.round((totalStats.assessedStudents / totalStats.totalStudents) * 100)
    : 0;
```

**2. `SummaryGrid`의 `needsAttention` 카드 색상 하드코딩**

`SummaryValue $color='#EF4444'`로 빨간색이 하드코딩되어 있습니다. `ComparisonSection`의 `KpiBoxValue $color='#DC2626'`와 다른 빨간색 톤을 사용하고 있어, 시각적 일관성이 다소 떨어집니다. 테마 컬러나 공통 상수로 통일하는 것이 좋습니다.

- **위치**: `TeacherDashboardPage.tsx` 라인 176
- **기존 코드**:
```tsx
<SummaryValue $color='#EF4444'>{totalStats.needsAttention}명</SummaryValue>
```
- **해결 방안 (수정 코드)**:
```tsx
<SummaryValue $color={theme.colors.danger ?? '#DC2626'}>{totalStats.needsAttention}명</SummaryValue>
```
> 단, `theme.colors.danger`가 실제로 정의되어 있는지 확인이 필요합니다. 정의되어 있지 않다면 `ComparisonSection`에서 사용 중인 `#DC2626`로 통일하는 것을 권장합니다.

**3. `ComparisonSection`의 `showSidePanel={false}`로 인한 정보 손실 가능성**

`TeacherDashboardPage`에서 `ComparisonSection`에 `showSidePanel={false}`를 전달하여 사이드 패널(전체 비교 요약, 선택 반 분석 요약)을 숨겼습니다. 이로 인해 사용자가 특정 반을 선택했을 때 해당 반의 상세 요약(T점수, 관심 필요 학생 수, 유형 분포)을 볼 수 없게 됩니다. 상단 `SummaryGrid`의 "상담 및 지도 필요" 카드가 전체 합계만 보여주므로, **반별 상세 정보 접근 경로가 사라진 것**입니다.

`showSidePanel={false}`의 의도가 "상단 요약 카드로 대체"라면, `SummaryGrid`의 각 카드를 클릭했을 때 해당 정보로 이동하거나, 최소한 반 선택 시 사이드 패널이 다시 나타나는 인터랙션이 필요할 수 있습니다.

- **위치**: `TeacherDashboardPage.tsx` 라인 198-199
- **제안**: `showSidePanel`을 `selectedClassId !== null`일 때만 `true`로 전환하는 방식
```tsx
<ComparisonSection
  classes={classes}
  selectedClassId={selectedClassId}
  onClassSelect={setSelectedClassId}
  onGoToClass={handleGoToClass}
  showDrillToggle={false}
  showSidePanel={selectedClassId !== null}
/>
```

1. `showSidePanel`이 `false`일 때 `selectedClass` 상태가 남아있으면, 이후 `true`로 전환될 때 이전 선택 상태가 그대로 유지됩니다. `showSidePanel`이 `false`로 전환될 때 `selectedClassId`를 초기화하는 로직이 필요할 수 있습니다.
   - **위치**: `ComparisonSection.tsx` 라인 370-372 (props 기본값 선언부)

   ```tsx
   showDrillToggle = true,
   showSidePanel = true,
   ```
   - **해결 방안 (수정 코드)**:
   ```tsx
   showDrillToggle = true,
   showSidePanel = true,
   // useEffect로 showSidePanel이 false가 되면 selectedClassId 초기화
   useEffect(() => {
     if (!showSidePanel) {
       onClassSelect(null);
     }
   }, [showSidePanel]);
   ```
   > 단, `useEffect` 추가 시 무한 루프 가능성이 있으므로, `onClassSelect`가 `useCallback`으로 감싸져 있는지 확인 후 적용해야 합니다.
