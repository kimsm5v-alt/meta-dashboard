## 변경 배경

이 커밋은 IDP(Identity Provider) 그룹 동기화 기능을 dev 환경에서 활성화하기 위한 설정 변경입니다.

- **목적**: dev 프로파일에서 `group-sync` 기능을 ON으로 전환하여 IDP 그룹 데이터를 주기적으로 동기화
- **변경 방향**: 기존에는 해당 설정이 없었으나, IdP의 `groups:read` scope와 마이그레이션 스크립트 적용을 전제로 기능을 활성화

## 변경사항 요약

`application-vs-dev.yml`에 `group-sync.enabled: true` 설정 블록과 상세 주석을 추가했습니다. 주석에는 사전조건(마이그레이션 SQL, IdP scope), 동작 방식(부트스트랩 -> 1분 폴링 -> 일1회 전체 재동기화), ShedLock을 통한 단일 인스턴스 실행 보장 등이 명시되어 있습니다.
