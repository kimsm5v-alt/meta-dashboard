## 개선 제안 (Medium)

### characteristics의 독립성 강화

현재 characteristics는 description의 내용을 축약하여 나열하는 형태입니다. 예를 들어 '몰입회복 탄력형'의 경우:

```
// description
'심리 정서적 자원이 풍부하고 메타인지 전략도 가장 우수하며 부담과 소진 수준은 가장 낮습니다. 학습 몰입과 성취 기대가 가장 높습니다.'

// characteristics
'심리/정서 자원 풍부'
'메타인지 전략 최우수'
'부담·소진 최저'
'학업 몰입·성취 기대 최고'
```

description의 각 문장이 그대로 characteristics의 항목으로 변환되어 있어, description을 읽은 후 characteristics를 볼 때 새로운 정보가 없습니다. characteristics는 description을 읽지 않고도 독립적으로 이해할 수 있는 별개의 요약 인사이트로 설계하면 더 좋습니다.

**제안**: characteristics를 행동 지향적 표현으로 변경하여 description과 차별화합니다.

```typescript
// 현재 (몰입회복 탄력형)
characteristics: [
  '심리/정서 자원 풍부',
  '메타인지 전략 최우수',
  '부담·소진 최저',
  '학업 몰입·성취 기대 최고',
],

// 제안
characteristics: [
  '풍부한 심리 자원으로 회복탄력성 높음',
  '최상위 수준의 자기주도 학습 역량',
  '학업 스트레스 관리가 매우 뛰어남',
  '학습 몰입과 성취 기대가 가장 높은 유형',
],
```

이렇게 변경하면 characteristics만 봐도 각 항목이 독립적인 인사이트를 제공하고, description을 보완하는 역할을 할 수 있습니다.
