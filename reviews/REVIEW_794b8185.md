## 변경 배경

이 커밋은 `StrategyCard` 컴포넌트의 심화 코칭(Advanced) 섹션에서 액션 아이템 목록의 시각적 표현을 개선하기 위한 UI 스타일 변경입니다.

- **목적**: 심화 코칭 액션 아이템 목록에 불릿(disc) 스타일을 적용하고, 각 항목 간 간격(margin-bottom)을 부여하여 가독성을 향상
- **도메인**: UI (프론트엔드 스타일링)
- **변경 방향**: 기존의 스타일 없는 `<li>` 태그를 전용 styled 컴포넌트(`AdvancedBullet`)로 교체하고, 부모 `<ul>`에 `list-style: disc`를 명시하여 목록의 시각적 계층을 명확히 함

## [GOOD] 잘된 점

- 스타일을 인라인 `<li>` 대신 전용 styled 컴포넌트(`AdvancedBullet`)로 분리하여 재사용성과 일관성을 확보했습니다.
- `list-style: disc`를 명시적으로 선언하여 브라우저 기본값에 의존하지 않고 의도된 목록 스타일을 보장했습니다.
- `margin-bottom: 4px`로 항목 간 간격을 세밀하게 조정하여 가독성을 개선했습니다.
- 기존 `AdvancedBullets`(styled.ul)의 구조를 유지하면서 최소한의 변경으로 목표를 달성했습니다.

## 변경사항 요약

`AdvancedBullets`에 `list-style: disc`를 추가하고, `AdvancedBullet`(styled.li) 컴포넌트를 신규 생성하여 심화 코칭 액션 아이템의 `<li>` 태그를 교체했습니다. 순수 스타일 개선으로 기능 로직에는 영향이 없습니다.

## 주요 파일 분석

### frontend/src/widgets/coaching/StrategyCard.tsx

**변경 내용:**
심화 코칭 액션 아이템 목록에 불릿 스타일과 항목 간 간격을 추가하는 스타일 개선.

**개선 제안:**
이번 변경 자체는 명확하고 완결적이어서 추가 수정이 필요하지 않습니다. `AdvancedBullet`의 `margin-bottom: 4px`는 마지막 항목에도 적용되어 목록 하단에 불필요한 여백이 생길 수 있으나, `AdvancedItem`의 `padding`과 결합 시 시각적으로 문제가 되지 않는 수준입니다. 만약 정밀한 여백 제어가 필요하다면 `:last-child` 선택자로 마지막 항목의 margin을 제거하는 방법을 고려할 수 있습니다.

```
// 선택적 개선 (마지막 항목 여백 제거)
const AdvancedBullet = styled.li`
  margin-bottom: 4px;
  &:last-child {
    margin-bottom: 0;
  }
`;
```
