## 변경 배경

이 커밋은 `LessonEditorPage.tsx`의 `handleSaved` 함수에서 저장 완료 모달(`savedOpen`)이 열리는 시점을 수정한 것입니다. 기존 코드는 `registerRefSet`(나의 자료 등록) 호출 직후, 성공 여부와 무관하게 `setSavedOpen(true)`가 즉시 실행되어 등록이 실패해도 저장 완료 모달이 열리는 문제가 있었습니다.

- **목적**: 나의 자료 등록이 실제로 성공했을 때만 저장 완료 모달이 열리도록 수정
- **도메인**: UI (프론트엔드 비즈니스 로직)
- **변경 방향**: 등록 성공/실패에 따른 UI 상태 분기를 명확히 하여, 실패 시에도 모달이 열리는 오동작을 제거

## [GOOD] 잘된 점

- 등록 실패 시 `onError`에서 `toast.error`를 띄우면서도 동시에 저장 완료 모달이 열리는 모순을 제거하여, 성공/실패 상태에 따른 UI 동작이 일관되게 되었습니다.
- `onSuccess` 콜백에 이미 `setSavedOpen(true)`가 존재하므로, 제거 후에도 정상 동작이 유지되는 안전한 수정입니다.
- 변경 범위가 한 줄로 최소화되어 회귀 위험이 낮습니다.

## 변경사항 요약

`handleSaved` 함수에서 `registerRefSet` 호출 직후 실행되던 `setSavedOpen(true)`를 제거하여, 저장 완료 모달이 `onSuccess` 콜백에서만 열리도록 수정했습니다. 이로써 등록 실패 시 모달이 열리지 않고 오류 토스트만 표시됩니다.
