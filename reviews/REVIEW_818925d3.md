```python
    keys = []
    base_key = os.getenv(f"{provider_prefix}_API_KEY")
    if base_key:
        keys.append(base_key)
    
    # 추가 키 확인 (_2, _3, ...)
    i = 2
    while True:
        extra_key = os.getenv(f"{provider_prefix}_API_KEY_{i}")
        if not extra_key:
            break
        keys.append(extra_key)
        i += 1
    return keys
```

**장점**:
- 다중 API 키 지원으로 페일오버(Failover) 기능 내재화
