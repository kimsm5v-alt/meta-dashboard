## 변경 배경

이 커밋은 AI 어시스턴트(FloatingAssistant) 위젯의 두 가지 개선을 포함합니다. 첫째, 화면 캡처 기능에서 AI 어시스턴트 UI 자체가 캡처 결과에 포함되지 않도록 `data-capture-ignore` 속성을 추가했습니다. 둘째, 대화 시작 전(EmptyState)에서만 사용되던 `remainingQuestions` 필터링 로직이 실제로는 항상 `questions`와 동일한 결과를 내는 데드 코드였음을 확인하고 이를 제거했습니다.

- **목적**: 화면 캡처 시 AI 어시스턴트 UI 제외 + 불필요한 필터링 로직 정리
- **도메인**: UI (프론트엔드 위젯)
- **변경 방향**: 캡처 품질 개선 및 코드 단순화

## [GOOD] 잘된 점

- `data-capture-ignore` 속성은 `shared/lib/captureRegion.ts`의 `CAPTURE_IGNORE_ATTR` 상수와 `html2canvas`의 `ignoreElements` 콜백에 이미 정의된 기존 패턴을 정확히 따르고 있어 일관성이 있습니다.
- `remainingQuestions` 제거는 실제로 EmptyState(대화 시작 전)에서만 사용되므로, 해당 시점에는 `hasConversation`이 항상 false여서 `remainingQuestions === questions`가 성립합니다. 즉, 동작 변화 없이 데드 코드를 안전하게 제거한 것입니다.
- `Overlay`와 `FullscreenBackdrop` 두 곳 모두에 속성을 적용하여 캡처 제외 범위를 일관되게 유지했습니다.

## 변경사항 요약

- `remainingQuestions`/`askedTexts` 변수와 필터링 로직을 제거하고 `questions.map`으로 단순화했습니다.
- `Overlay`와 `FullscreenBackdrop`에 `data-capture-ignore='true'`를 추가하여 화면 캡처에서 AI 어시스턴트 UI를 제외했습니다.

**개선 제안:**

1. `data-capture-ignore` 속성값을 상수로 통일
   - **위치 (라인 번호)**: 884, 923
   - **기존 코드**:
```tsx
<Overlay data-capture-ignore='true'>
...
{isFullscreen && <FullscreenBackdrop data-capture-ignore='true'>{panel}</FullscreenBackdrop>}
```
   - **해결 방안 (수정 코드)**:
```tsx
import { CAPTURE_IGNORE_ATTR } from '../../shared/lib/captureRegion';
...
<Overlay {...{ [CAPTURE_IGNORE_ATTR]: 'true' }}>
...
{isFullscreen && <FullscreenBackdrop {...{ [CAPTURE_IGNORE_ATTR]: 'true' }}>{panel}</FullscreenBackdrop>}
```
   - **주의사항**: `Overlay`가 styled-component인지, 속성 전달 방식에 제약이 있는지에 따라 위 스프레드 문법이 동작하지 않을 수 있어, 실제 적용 시 컴포넌트 정의를 추가로 확인할 필요가 있습니다. 이 제안은 선택적 개선 사항이며, 현재 하드코딩 방식도 기존 `CaptureOverlay.tsx` 패턴과 일관되므로 필수는 아닙니다.
