## [GOOD] 잘된 점
CP님의 변경 사항은 학습심리정서검사 시스템의 사용자 경험을 개선하는 의미 있는 수정입니다. 다음 세 가지 측면에서 긍정적으로 평가합니다:

1. **사용자 중심 설계**: 교사가 학생 ID보다 닉네임을 통해 미제출 학생을 식별하는 것이 훨씬 직관적입니다. 실제 교육 현장에서는 `mathbe2-s2` 같은 ID보다 "홍길동" 같은 닉네임이 더 의미 있는 식별자 역할을 합니다.

2. **문서-코드 일관성**: API 스펙 문서(`dgnss-api-spec.md`)와 실제 구현(`DgnssMapper.xml`)을 동시에 업데이트하여 문서와 실제 시스템 동작이 일치하도록 관리했습니다. 이는 협업과 유지보수에 매우 중요합니다.

3. **데이터 관계 적절한 활용**: 기존 쿼리에 `group_member` 테이블을 JOIN하여 닉네임 정보를 정확하게 가져오는 방식은 데이터베이스 설계를 잘 이해하고 활용한 것입니다.

## 변경사항 요약
학습심리정서검사 미제출 인원 조회 API(`GET /api/dgnss/tc/notsubm`)의 응답 구조를 학생 ID에서 닉네임으로 변경했습니다. MyBatis 매퍼 쿼리 수정과 API 문서 업데이트를 함께 수행했습니다.

### 🟠 High (우선 수정 권장)
1. **UTF-8 BOM 추가 문제**
   - **문제점**: `backend/docs/dgnss-api-spec.md` 파일 시작 부분에 UTF-8 BOM(﻿)이 추가되었습니다.
   - **코드 증거**: diff 출력에서 `@@ -1,4 +1,4 @@` 라인 아래 `-# 학습심리정서검사 API 연동 규격서`가 `+﻿# 학습심리정서검사 API 연동 규격서`로 변경된 것을 확인할 수 있습니다.
   - **영향**: BOM은 일부 텍스트 처리 도구, CI/CD 파이프라인, Git diff에서 문제를 일으킬 수 있으며 불필요한 변경으로 표시됩니다.
   - **해결 방안**: 코드 편집기에서 "UTF-8 without BOM" 인코딩으로 파일을 다시 저장하여 BOM을 제거하세요.

2. **데이터 누락 가능성 증가**
   - **문제점**: 새로운 JOIN 조건(`gm.status = 'ACTIVE'`)으로 인해 비활성 상태 학생이 결과에서 제외될 수 있습니다.
   - **코드 증거**: 변경된 쿼리에서 `INNER JOIN group_member gm ON gi.group_id = gm.group_id AND a1.stdt_id = gm.stdt_id AND gm.status = 'ACTIVE'` 조건을 확인할 수 있습니다.
   - **영향**: `group_member` 테이블에 존재하지 않거나 `status`가 'ACTIVE'가 아닌 학생은 미제출 목록에서 누락됩니다. 이는 교사가 모든 미제출 학생을 확인하지 못하는 상황으로 이어질 수 있습니다.
   - **해결 방안**: 
     - 이 변경이 의도된 것인지 요구사항을 재확인하세요.
     - 모든 미제출 학생을 보고 싶다면 `LEFT JOIN`으로 변경하거나 `status` 조건을 제거하는 것을 고려하세요.
     - 변경 전후 데이터 일관성을 테스트하여 실제 영향도를 파악하세요.
