## 변경 배경

이 커밋은 학생용 검사 목록 페이지(`MyExamListPage.tsx`)의 UI 스타일을 테마 토큰 기반에서 하드코딩된 값으로 전환하고, 검사 상태 배지의 색상 팔레트를 Tailwind 계열의 더 밝고 선명한 색상으로 교체한 변경입니다. 또한 `ExamCard` 내부에서 상태 메시지와 액션 버튼의 렌더링 순서를 조정했습니다.

- **목적**: 디자인 시안에 맞춘 색상/간격 미세 조정 및 상태 배지 가독성 개선
- **도메인**: UI (프론트엔드 스타일링)
- **변경 방향**: 테마 토큰 의존을 줄이고 명시적인 픽셀/색상 값으로 대체하여 스타일을 고정

## [GOOD] 잘된 점

- 상태별 색상이 Tailwind 표준 팔레트로 통일되어 배경색과 텍스트색의 대비가 개선되고 일관성이 높아졌습니다. 예를 들어 `waiting` 상태는 기존 `#dbeafe`/`#1d4ed8`에서 `#eff6ff`/`#2563eb`로 변경되어 더 밝은 배경에 선명한 텍스트가 적용되었습니다.
- `line-height`를 명시적으로 추가하여 텍스트 렌더링이 브라우저 기본값에 의존하지 않도록 개선했습니다. `PageTitle`에 `line-height: 32px`, `PageSubtitle`에 `line-height: 24px` 등이 추가되었습니다.
- `StatusMessage`와 `ExamActions`의 순서 변경은 상태 안내 문구가 액션 버튼보다 먼저 보이도록 하여 UX 흐름이 자연스러워졌습니다. 기존에는 액션 버튼이 먼저 렌더링된 후 상태 메시지가 표시되었으나, 이제 상태 메시지가 먼저 표시됩니다.

## 변경사항 요약

`getStatusColor`의 상태별 색상 팔레트를 Tailwind 계열로 교체하고, `MyExamListPage.tsx`의 여러 styled-component에서 테마 토큰을 하드코딩된 픽셀/색상 값으로 대체했습니다. `ExamCard` 내부 렌더링 순서(StatusMessage → ExamActions)를 조정했습니다.

1. **테마 토큰 제거로 인한 일관성 저하**

   이번 변경은 `theme.spacing`, `theme.colors`, `theme.typography` 토큰을 하드코딩 값으로 대체했습니다. 이는 해당 페이지가 테마 시스템에서 분리되는 결과를 초래하며, 향후 다크 모드나 디자인 토큰 변경 시 이 파일만 별도로 수정해야 하는 유지보수 부담이 생깁니다.

   - **위치 (라인 번호)**: `MyExamListPage.tsx` 전반 (PageRoot ~ SectionCount)
   - **기존 코드**:
   ```
   const PageTitle = styled.h1`
     font-size: ${({ theme }) => theme.typography.fontSize['2xl']};
     font-weight: ${({ theme }) => theme.typography.fontWeight.bold};
     color: ${({ theme }) => theme.colors.text.primary};
   `;
   ```
   - **해결 방안 (수정 코드)**: 테마 토큰을 유지하거나, 하드코딩이 불가피하다면 상수로 추출하여 재사용성을 확보하는 것을 권장합니다.
   ```
   const PageTitle = styled.h1`
     font-size: ${({ theme }) => theme.typography.fontSize['2xl']};
     line-height: 32px;
     font-weight: ${({ theme }) => theme.typography.fontWeight.bold};
     color: ${({ theme }) => theme.colors.text.primary};
   `;
   ```
   > **[수정 코드 제시 의무 절차]** 해당 파일의 styled-component 전반을 `read_file`로 확인했습니다. 다만 이 제안은 디자인 방향(테마 유지 vs 하드코딩)에 대한 팀 결정이 필요하므로, 실제 적용 여부는 팀 컨벤션에 따라 판단하시기 바랍니다.

2. **색상 하드코딩의 중복**
