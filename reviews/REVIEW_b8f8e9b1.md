### 개선 필요 요소 (Areas for Improvement)

**High 우선순위 이슈**

**1. context_data의 None 처리 문제**
```python
# 현재 코드 (문제점)
context_data = None  # JSON 파싱 실패 시
# 이후 API 호출 시 None이 전달됨 → 서버 측 처리 불확실
```

**개선 제안:**
```python
# 수정 코드
try:
    context_data = json.loads(context_input) if context_input.strip() else {}
except json.JSONDecodeError:
    st.error("올바른 JSON 형식이 아닙니다. 기본 빈 객체로 대체합니다.")
    context_data = {}
```

**문제점 분석:**
- API 서버가 `None` 값을 기대하는지 명확하지 않음
- 빈 객체(`{}`)로 대체하는 것이 더 안전한 접근법
- 사용자에게 명확한 피드백 제공

**2. 이모지 사용의 일관성 문제**
```python
# 현재 코드 (프로젝트 컨벤션 위반 가능성)
message_placeholder.markdown(f"❌ {error_msg}")
```

**개선 제안:**
```python
# 수정 코드
message_placeholder.markdown(f"**오류**: {error_msg}")
```

**근거:**
- 프로젝트 전체 코드베이스에서 이모지 사용 패턴 확인 필요
- 텍스트 기반 오류 표시가 더 접근성 높음
- UI/UX 일관성 유지

**2. 타입 힌트 부재**
