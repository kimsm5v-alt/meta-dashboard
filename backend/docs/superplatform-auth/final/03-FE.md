# 3. Frontend 수정 계획

> Auth Client SDK 탑재 + 자체 인증 로직 제거

---

## 3.1 핵심 변경

| AS-IS | TO-BE |
|-------|-------|
| 자체 로그인 폼 (email/password) | Auth 서버 로그인 페이지로 리다이렉트 (SDK) |
| Axios interceptor 자체 Silent Refresh (~170줄) | SDK `getAccessToken()` / `refreshAccessToken()` |
| AuthContext에서 localStorage 직접 관리 | SDK가 토큰 저장/관리 |
| 자체 회원가입 페이지 | Auth 서버 회원가입 (제거) |
| 자체 비밀번호 찾기 | Auth 서버 비밀번호 재설정 (제거) |

### TypeScript 타입 선언

Hub 프로젝트의 `sample-react/auth.ts`를 참고하여 타입 선언 파일 생성.

**경로**: `frontend/src/shared/lib/authClient.ts`

```typescript
// SDK 전역 타입 선언
interface AuthClientOptions {
  authUrl: string;
  clientId: string;
  redirectUri: string;
  apiUrl?: string;
  paths?: { token?: string; refresh?: string; logout?: string; };
  postLogoutRedirectUri?: string;
  tokenStorage?: 'localStorage' | 'cookie';
  touchEnabled?: boolean;
  touchIntervalMs?: number;
}

interface AuthUser {
  publicUserId: string;
  email: string;
  name: string;
  userType: string;
}

interface RedirectResult {
  type: 'callback' | 'normal';
  authenticated: boolean;
  user: AuthUser | null;
  returnPath?: string;
  error?: string;
}

interface SilentLoginResult {
  success: boolean;
  reason?: 'no_session' | 'expired' | 'network';
}

interface AuthClientInstance {
  login(options?: { redirectPath?: string }): Promise<void>;
  logout(): Promise<void>;
  getUser(): AuthUser | null;
  isAuthenticated(): boolean;
  getAccessToken(): string | null;
  refreshAccessToken(): Promise<string | null>;
  handleRedirectResult(): Promise<RedirectResult>;
  trySilentLogin(): Promise<SilentLoginResult>;
  setGuestToken(accessToken: string): void;
  onAuthChange(cb: (user: AuthUser | null) => void): () => void;
  authorizedFetch(input: RequestInfo | URL, init?: RequestInit): Promise<Response>;
  startActivityTracking(): void;
  stopActivityTracking(): void;
}

declare const AuthClient: {
  init(options: AuthClientOptions): Promise<AuthClientInstance>;
};

// 싱글턴 인스턴스 관리
let authInstance: AuthClientInstance | null = null;

export async function initAuth(): Promise<AuthClientInstance> {
  authInstance = await AuthClient.init({
    authUrl: import.meta.env.VITE_SP_AUTH_URL,
    clientId: import.meta.env.VITE_SP_CLIENT_ID,
    redirectUri: window.location.origin + '/auth/callback',
    postLogoutRedirectUri: window.location.origin + '/login',
  });
  return authInstance;
}

export function getAuth(): AuthClientInstance {
  if (!authInstance) throw new Error('Auth SDK not initialized');
  return authInstance;
}

export type { AuthClientInstance, AuthUser, RedirectResult };
```

## 3.3 React 훅

**경로**: `frontend/src/shared/hooks/useSpAuth.ts`

Hub의 `useAuth.ts`를 참고. `useSyncExternalStore` 기반.

```typescript
import { useSyncExternalStore, useCallback } from 'react';
import { getAuth } from '@shared/lib/authClient';
import type { AuthUser } from '@shared/lib/authClient';

export function useSpAuth() {
  const auth = getAuth();

  const user = useSyncExternalStore<AuthUser | null>(
    (cb) => auth.onAuthChange(cb),
    () => auth.getUser(),
  );

  return {
    user,
    isAuthenticated: user !== null,
    login: useCallback(
      (redirectPath?: string) => auth.login({ redirectPath }),
      [auth],
    ),
    logout: useCallback(() => auth.logout(), [auth]),
    getAccessToken: useCallback(() => auth.getAccessToken(), [auth]),
  };
}
```

## 3.4 main.tsx — 부트스트랩 변경

**핵심**: SDK init → handleRedirectResult → replaceState → createRouter 순서.

```typescript
import { createRoot } from 'react-dom/client';
import { RouterProvider } from 'react-router-dom';
import { initAuth } from '@shared/lib/authClient';
import { createRouter } from '@app/router/routes';
import { Providers } from '@app/providers';

const PUBLIC_PATHS = ['/guest', '/group/join', '/join'];

async function bootstrap() {
  // 1) SDK 초기화
  const auth = await initAuth();

  // 2) 콜백 처리 + 세션 복구
  const result = await auth.handleRedirectResult();

  if (result.type === 'callback') {
    if (result.authenticated) {
      window.history.replaceState(null, '', result.returnPath || '/');
    } else if (result.error === 'consent_denied') {
      window.history.replaceState(null, '', '/login');
    }
  } else if (!result.authenticated) {
    const isPublic = PUBLIC_PATHS.some((p) =>
      window.location.pathname.startsWith(p),
    );

    if (!isPublic) {
      const silent = await auth.trySilentLogin();
      if (!silent.success && !auth.isAuthenticated()) {
        // 미인증 → 라우터에서 로그인 페이지로 리다이렉트
      }
    }
  }

  // 3) replaceState 이후에 라우터 생성 (React Router 주의사항)
  const router = createRouter();

  // 4) React 렌더
  createRoot(document.getElementById('root')!).render(
    <Providers>
      <RouterProvider router={router} />
    </Providers>,
  );
}

bootstrap();
```

**주의**: `createBrowserRouter()`는 **모듈 최상위에서 호출하면 안 됨**. `replaceState()` 이후에 호출해야 콜백 URL이 아닌 실제 URL로 라우터가 초기화됨.

## 3.6 AuthContext.tsx — SDK 기반 교체

### 제거 대상

```typescript
// 전부 제거
loginWithCredentials()   // 테스트 로그인
loginWithEmail()         // 이메일/비밀번호 로그인
signUp()                 // 회원가입
sendCode()               // 이메일 인증코드 발송 (가입용)
verifyCode()             // 이메일 인증코드 확인 (가입용)

// localStorage 직접 관리 제거
localStorage.getItem('auth_token')     // SDK가 관리
localStorage.getItem('refresh_token')  // SDK가 관리
localStorage.getItem('meta_auth_user') // SDK getUser()로 대체
```

### 유지/변경

```typescript
// 게스트 로그인 — SDK setGuestToken 사용으로 변경
loginAsGuest(info) → auth.setGuestToken(info.accessToken)

// 사용자 정보 — SDK getUser()에서 가져오되, 학심정 추가 데이터(roleCode, tcId 등)는 별도 조회
updateUser()  // 학심정 서비스 데이터 업데이트용으로 유지

// 로그아웃 — SDK logout() 사용
logout() → auth.logout()
```

### 새로운 AuthContext 구조

```typescript
interface AuthContextType {
  user: User | null;          // SDK user + 학심정 서비스 데이터 병합
  isAuthenticated: boolean;
  isLoading: boolean;
  loginAsGuest: (info: GuestLoginInfo) => void;
  updateUser: (updates: Partial<User>) => void;
  logout: () => void;
  // 게스트 이메일 인증 (학심정 자체 유지)
```

## 3.7 client.ts — Silent Refresh 제거

### 제거 대상 (~150줄)

```typescript
// 전부 제거
let isRefreshing = false;
let failedQueue: Array<...> = [];
const processQueue = (...) => { ... };
const tryRefreshToken = async (): Promise<string> => { ... };

// 응답 인터셉터의 401 → refresh → retry 로직 제거
```

### 변경 후 (~30줄)

```typescript
import { getAuth } from '@shared/lib/authClient';

// 요청 인터셉터 — SDK에서 AT 가져와서 주입
axiosInstance.interceptors.request.use((config) => {
  const auth = getAuth();
  const isPublic = PUBLIC_ENDPOINTS.some((ep) => config.url?.includes(ep));
  if (!isPublic) {
    const token = auth.getAccessToken();
    if (token) {
      config.headers.Authorization = `Bearer ${token}`;
    }
  }
  return config;
});

// 응답 인터셉터 — 401 시 SDK refresh 후 재시도
axiosInstance.interceptors.response.use(
  (response) => {
    const data = response.data as APIResponse<unknown>;
    if (data && data.success === false) {
      return Promise.reject(new ApiError(response.status, data.resultMessage, data.resultCode));
    }
    return response;
  },
  async (error) => {
    const originalRequest = error.config;
    if (error.response?.status === 401 && !originalRequest._retry) {
      originalRequest._retry = true;
      const auth = getAuth();
      const newToken = await auth.refreshAccessToken();
      if (newToken) {
        originalRequest.headers.Authorization = `Bearer ${newToken}`;
        return axiosInstance(originalRequest);
      }
      // refresh 실패 → SDK가 자동으로 clearTokens + 로그아웃 처리
    }
    const message = error.response?.data?.resultMessage ?? error.message ?? 'API Error';
    return Promise.reject(new ApiError(error.response?.status ?? 0, message));
  },
);
```

## 3.8 CompleteProfilePage.tsx — 추가 정보 입력 (신규)

**경로**: `frontend/src/pages/auth/CompleteProfilePage.tsx`

SSO 최초 로그인 후 학심정 user가 없을 때 리다이렉트되는 페이지.

```tsx
export const CompleteProfilePage = () => {
  const { user } = useSpAuth();
  const [gender, setGender] = useState<'M' | 'F' | ''>('');
  const [roleCode, setRoleCode] = useState<'TEACHER' | 'STUDENT' | ''>('');
  const navigate = useNavigate();

  // userType이 UNSET이 아니면 역할 선택 숨김
  const needsRoleSelection = user?.userType === 'UNSET';

  const handleSubmit = async () => {
    await apiClient.post('/api/v1/user/complete-profile', {
      gender,
      roleCode: needsRoleSelection ? roleCode : undefined,
    });
    navigate(roleCode === 'STUDENT' ? '/student/exams' : '/dashboard', { replace: true });
  };

  return (
    <Container>
      <Title>서비스 이용을 위해 추가 정보를 입력해주세요</Title>

      {needsRoleSelection && (
        <RoleSelector>
          <RoleOption selected={roleCode === 'TEACHER'} onClick={() => setRoleCode('TEACHER')}>
            교사
          </RoleOption>
          <RoleOption selected={roleCode === 'STUDENT'} onClick={() => setRoleCode('STUDENT')}>
            학생
          </RoleOption>
        </RoleSelector>
      )}

      <GenderSelector>
        <GenderOption selected={gender === 'M'} onClick={() => setGender('M')}>남</GenderOption>
        <GenderOption selected={gender === 'F'} onClick={() => setGender('F')}>여</GenderOption>
      </GenderSelector>

      <SubmitButton onClick={handleSubmit} disabled={!gender || (needsRoleSelection && !roleCode)}>
        시작하기
      </SubmitButton>
    </Container>
  );
};
```

**라우트 추가** (`routes.tsx`):
```typescript
{ path: '/auth/complete-profile', element: <CompleteProfilePage /> }
```

**리다이렉트 조건** (SsoUserService 또는 FE에서 판단):
- SSO 로그인 성공 → 학심정 user 조회 → 없음 → `/auth/complete-profile`로 리다이렉트
- 학심정 user 있음 → 바로 대시보드

## 3.12 게스트 플로우 — FE 변경

현행 게스트 플로우의 FE 부분은 대부분 유지. 변경점:

| 단계 | 현행 | 변경 |
|------|------|------|
| 초대코드 입력 | 그대로 | 그대로 |
| 이메일 인증 | `apiClient.post('/member/send-code')` | **그대로 유지** |
| 이메일 코드 검증 | `apiClient.post('/member/verify-code')` | **그대로 유지** |
| 게스트 인증 | `apiClient.post('/guest/auth')` | **그대로 유지** (백엔드가 Auth 게스트 토큰으로 교체) |
| 토큰 저장 | `localStorage.setItem('auth_token', ...)` | **`auth.setGuestToken(accessToken)`** ← SDK 사용 |
| AuthContext | `loginAsGuest(info)` | `auth.setGuestToken(at)` + 학심정 서비스 데이터 별도 세팅 |

핵심: **백엔드 응답 형식이 동일하면 프론트 호출 코드는 거의 안 바뀜**. 토큰 저장만 SDK로 변경.
