## 카테고리

MVP는 2개 카테고리 (교사/학생 동일 구조).

| 카테고리 | 교사 이벤트 | 학생 이벤트 |
|---|---|---|
| 검사 | T3, T4, T5, T6 | S1, S2, S3, S6 |
| 그룹 | T1, T2 | S4, S5 |

*1차 고도화 시 '활동' 카테고리 추가 예정 (T7~T9)*

## 교사용 알림 이벤트

| # | 그룹핑 | 이벤트 | 발생 시점 | 채널 | 딥링크 | 문구 |
|---|---|---|---|---|---|---|
| T1 | 그룹 | 그룹 초대 수락 | 학생이 초대 링크/코드로 그룹 가입 완료 | 인앱 | `/groups/{id}` | %닉네임% 학생이 '%그룹명%' 그룹에 참여했습니다. |
| T2 | 그룹 | 학생 그룹 탈퇴 | 학생이 그룹에서 나갔을 때 | 인앱 | `/groups/{id}` | %닉네임% 학생이 그룹을 탈퇴했습니다. |
| T3 | 검사 | 학생 검사 제출 (개별) | 제출 API 성공 | 인앱 | `/assessment` | %닉네임% 학생이 N차 %검사명%를 제출했습니다. |
| T4 | 검사 | 검사 전체 완료 | 배정 인원 100% 제출 | 인앱 | `/assessment` | %그룹명% N차 %검사명% 전원 제출이 완료되었습니다. [검사 종료] 시 리포트가 생성됩니다. |
| T5 | 검사 | 미제출 리마인더 (교사) | 검사 시작 D-3 ~ D-1, 매일 오전 8시 1회 | 인앱 | `/assessment` | %그룹명% N차 %검사명% 기한 마감 %남은 일수%일 전입니다. 미제출한 학생이 있다면 검사 진행을 안내해 주세요. |
| T6 | 검사 | 검사 종료 | 집계 배치 완료 | 인앱 | `/dashboard` | %그룹명% N차 %검사명% 리포트가 생성되었습니다. 대시보드에서 결과를 확인해 보세요. |

## UI / 동작 규칙

| 항목 | 결정 사항 |
|---|---|
| 읽음/안읽음 | 개별 읽음 + "모두 읽음" 버튼 제공 |
| 모두 읽음 활성화 | 안읽음 9개 이상일 때만 활성화 |
| 뱃지 카운트 | 벨 아이콘 숫자 표시, 100 이상은 "99+" |
| 알림 묶기 | 개별 표시 (MVP) |
| 정렬 | 카테고리별 섹션, 각 섹션 내 최신순 |
| 빈 섹션 | 숨김 |
| 빈 상태 문구 | "아직 알림이 없어요" (교사/학생 공통) |
| 보관 정책 | 90일 자동 삭제 |
| 사용자 수동 삭제 | 없음 |
| 발송 시간대 | 제한 없음 (인앱 알림) |
| 닉네임 박제 | 알림 생성 시점 닉네임 문자열로 저장, 이후 변경/탈퇴 무관 ⚠️ 법무 확인 필요 |
